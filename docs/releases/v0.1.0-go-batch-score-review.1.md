# 围棋批量终局审校

新增批量审校脚本，读取已确认的死子决定，调用原生程序生成独立棋谱及证据清单。重复执行核对文件散列，清单通过临时文件原子替换。

离线验证覆盖重复槽、越界坐标、输入输出目录冲突、重复执行及证据变更。Pixel_7_Pro 上的隔离副本测试确认空死子复核的棋谱字节一致。正式样本仍需逐局确认死子。

发布源码。围棋独立评测保留 112 个完整槽位及一个中断槽位，后续槽位继续执行。
