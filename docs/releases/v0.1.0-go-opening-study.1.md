# 围棋开局学习与自动续弈

- 模式页新增六条项目自编开局线路，覆盖 9、13、19 路，支持逐着说明、定位和调速播放。
- 通过教程与难度资格后，可从线路末端启动 KataGo 自动训练。替换活动前需确认，训练结果与人机成长隔离。
- 36 项 JVM 和 6 次 Pixel 7 Pro 测试调用通过，核对两档字号的 6 张截图。Debug 双 ABI、仪器 APK、Release Manifest 通过，Lint 为 0 错误。
