# 围棋自动演局、棋谱与精彩收藏

- 自动演局记住上次选择的倍速，返回时以暂停状态打开。正式对局播放落子、提子和终局提示音，并遵循全局音效开关。
- 单局自动演局在双方确认终局后立即保存棋谱。支持按大师档、160 着或最终胜方曾落后五枚提子自动收藏，保留玩家手动收藏状态。
- 57 项 JVM、双 ABI Debug APK、仪器 APK、Release Manifest 通过，Lint 0 错误。Pixel 7 Pro 普通和 150% 字号各 6 项通过，核看 10 张截图。
