# 国标麻将十三幺实战题

新增「留十三种幺九字」实战题。玩家实际弃牌、摸白板并确认自摸，原生竞赛规则核对十三幺 88 番。旧训练及奖励保留，目录扩至 18 题。

11 项 JVM 用例、两档字号共 3 项模拟器用例、双 ABI 构建及 Debug Lint 通过，已核看 9 张画面。该节点发布源码，实体设备与完整题库仍待验收。
