# 国标麻将自动演局存档与回放

- Room 保存自动活动、播放设置及十六盘归档，支持收藏、删除和精确回放。自动演局独立于人类成长。
- 备份包含独立自动演局记录，Native 逐盘准入。验证存档失败回滚、数据库迁移与重开、备份替换及伪造牌墙拒绝。
- 77 项 JVM 和 13 项 Pixel 7 Pro 用例通过，核对两档字号的 5 张截图。Debug 双 ABI、测试 APK、Release Manifest 通过，Lint 0 错误。
