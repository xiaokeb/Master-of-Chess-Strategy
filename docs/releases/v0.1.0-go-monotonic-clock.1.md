# 围棋同次开机内稳定计时

本地双人、人机和双 AI 使用 Android 开机后的单调时间累计主时限，屏幕休眠也计入。应用重启后，同次开机复用本机时间基准。设备重启时重新从系统时间建立基准，现有围棋计时记录可继续读取。

50 个定向 JVM 测试通过，覆盖时钟前拨、回拨以及重建时间源。Pixel 7 Pro 复验了生产入口和两种 AI 模式的超时恢复，真实关闭隔离进程后，计时基准文件散列一致，终局仍只归档一次。双 ABI Debug、仪器 APK、Release Manifest 和 Lint 通过。此次发布源码。模拟器设备时钟保持原设置，实际手动改时与实体设备长局待验收。
