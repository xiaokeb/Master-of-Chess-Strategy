# 本地备份逐行读取

备份在原始输入上核对 SHA-256，然后逐行严格解码 UTF-8，省去正文的整份文本和字节副本。容器格式和 128 MiB 字节上限保持。

42 项 JVM、双 ABI 构建及 3 项 Pixel 7 Pro 模拟器回归通过。核对了围棋设置页的 6 张普通字号截图，以及国标麻将新版 WMO 十六盘档案恢复。128 MiB 测试使用带旧格式空行的解码夹具。实体设备和实际接近上限的档案性能待验收。本节点发布源码。
