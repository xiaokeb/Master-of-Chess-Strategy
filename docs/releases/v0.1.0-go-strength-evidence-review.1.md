# 围棋棋力证据与死子审校

新工具可离线核对两档换色的原始记录，查看终局棋组的 Benson 判定，并在 144 局审校证据齐备后计算三个棋力区间。

已离线核对 96 局原始独立样本。审校工具在 Pixel_7_Pro 模拟器通过 6 盘诊断棋谱和一盘已知净活与死子夹具。统计脚本用模拟数据验证了开局配对、验收区间和证据缺失、变更时的拒绝行为。

本次发布源码。其余 48 局、逐局死子审校及正式棋力结论待完成。
