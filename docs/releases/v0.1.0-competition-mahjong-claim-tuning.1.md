# 国标麻将吃碰杠与四档棋力诊断

新增大师档选择性吃碰杠及八番听牌估值的诊断策略。v4 在 1,536 盘训练后冻结 v5，再用 24 个未曝光种子完成 4,608 盘独立验收。中等对简单、大师对困难达到事前标准。困难对中等的比较得分为 80.86%，超过 80% 上限。正式人机与自动演局继续沿用原策略。

两个 ABI 的 Debug 构建、仪器测试 APK、Release Manifest 和 Lint 已核验。Pixel 7 Pro 复验正式赛事私有重放及自动演局旧档兼容。本次发布源码与评测证据，未附 APK。正式对局的新策略接入、实体设备性能和正式四档棋力验收仍未完成。
