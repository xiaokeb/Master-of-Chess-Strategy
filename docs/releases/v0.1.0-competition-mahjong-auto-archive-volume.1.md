# 国标麻将自动演局档案容量

Pixel 7 Pro 模拟器验证了 100 场与 500 场混合策略档案的导出、恢复和重新打开数据库。恢复后的活动、归档、收藏与保存时间一致，载荷逐条字节相同，人类战绩为空。

100 场导出／恢复分别约 83.3／82.8 秒，500 场约 409.9／407.5 秒。此次源码预发行提供容量测试与基线，后续核验回放优化和实体设备耗时。
