# 国标麻将自动演局新版计分

新建标准发牌演局使用修订后的 WMO 计分。已有演局和两份指定开局按原版本恢复。新版支持续局、归档、回放和备份，并校验逐盘计分版本。

NDK 双 ABI 构建、57 项 JVM 测试和 18 项模拟器用例通过。检查了两档字号，并在第 15 盘结束及第 16 盘归档后分别执行进程重启验收。

本次发布源码。正式人机赛事的新版计分和实体设备待独立验收。
