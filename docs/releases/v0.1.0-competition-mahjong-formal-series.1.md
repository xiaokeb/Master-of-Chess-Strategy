# 国标麻将整场赛事与旧档保留

可重放但缺少难度和辅助记录的旧档，现可明确确认保留后新开赛事。旧档仍可随全量备份导出。逐盘成绩单现在区分玩家编号和分数。

模拟器通过完整十六盘、磁盘重开、末盘撤回与重结算，以及两档字号下的历史查看、收藏与删除。确认删除成绩单后，赛事统计仍保留。通过 28 项 JVM 和 25 个设备测试方法，共采纳 28 次设备调用。

本次发布源码。可信胜场、高难度、完整横屏与音画、杀进程恢复和实体设备仍待后续验收。详见[验收报告](../games/competition-mahjong/2026-11-08-formal-series-verification.md)与[发布清单](manifests/v0.1.0-competition-mahjong-formal-series.1.json)。
