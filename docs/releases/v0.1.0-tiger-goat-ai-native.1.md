# 老虎吃羊棋：原生 AI 与安全快照桥

阶段源码预发布，不是完整 App 人机模式。

- 迭代加深 Alpha-Beta 以实际换手计深度，沿用项目 B 型规则、完整合法动作及可自愿结束的虎连跳；没有新增第三方引擎或权重。
- 独立 MOCT 快照 JNI/Kotlin 请求支持单次执行、合作式预算、显式取消、失败闭合和结果撤销，不借用活棋局句柄或阻塞其关闭锁。
- 定向 JVM 20/20、真实 JNI 新8＋既有5通过；同源原生10组不重复累计。双 ABI 构建、独立 CMake 目标与 Lint（0错误/6提醒）通过。
- 验收和源码身份见 `docs/games/tiger-goat/2026-10-18-ai-native-verification.md` 及同名机器清单。
