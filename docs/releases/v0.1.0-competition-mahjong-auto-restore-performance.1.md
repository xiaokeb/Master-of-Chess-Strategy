# 国标麻将回放优化

单盘恢复在独立候选上逐步校验。自动演局只有多个合法动作时才计算策略选择。模拟器对照中，两版生成并还原的 32 盘日志逐字节一致。

100 场混合策略档案在同一模拟器导出／恢复分别从 83.340／82.775 秒降至 69.624／69.393 秒。NDK 双 ABI、48 项 JVM 测试、Lint 和 24 次模拟器用例调用通过。

本次发布源码。优化后的 500 场耗时及实体设备表现待验收。
