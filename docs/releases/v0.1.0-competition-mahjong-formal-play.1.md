# 国标麻将正式赛事入口

首页可选择初始座位，进入十六盘赛事大厅。完成四章教程后开放简单难度，可开始或继续赛事，并查看同一座位的统计与历史。可迁移旧档由玩家预览、确认，原档保留。牌桌先显示本家手牌，出牌操作紧随其后。

- 110 项 JVM 测试及 Pixel 7 Pro 模拟器 38 个设备方法、40 次调用通过。
- 普通和 150% 字号实测首页进入、实际出牌、返回和同局续赛，检查 22 张原始截图。
- NDK 30 LLVM 双架构、Debug APK、测试 APK 与 Release Manifest 通过。Lint 0 错误、24 警告。

本次为源码预发布。整场十六盘、末盘结算与非空历史的设备验收仍待完成。高难度、旧档保留后直接新开、完整横屏、杀进程与实体设备也待后续验收。详见[验收报告](../games/competition-mahjong/2026-11-08-formal-host-verification.md)与[发布清单](manifests/v0.1.0-competition-mahjong-formal-play.1.json)。
