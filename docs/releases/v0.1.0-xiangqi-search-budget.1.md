# 中国象棋：搜索预算安全节点

源码预发布 `v0.1.0-xiangqi-search-budget.1`，基于围棋本地数据节点 `c62df0c7c8d87d7242e077052028cf5d484f6b48`，不是中国象棋或全项目最终版。

## 范围

Pikafish静态搜索复用现有时间/节点预算并响应停止；普通搜索在撤销走子、空步及同层状态后安全传播中断，避免占位分数驱动重搜、PV或缓存搜索边界。每轮重置轮询计数，不改变权重、生产难度参数或游戏规则。保留原上游版权/GPL、修改记录及NNUE独立限制。

补齐真实原生专项及独立构建/运行工具，并修正两条旧设备测试断言：自然限着按已确认的2020申请审核，不因导入的不完整历史自动判和；已发布存档协议为v3。主工作区尚未发布的v4规则/测试不混入本节点。
