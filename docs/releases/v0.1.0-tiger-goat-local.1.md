# 老虎吃羊棋：本地双人节点

阶段预发布 `v0.1.0-tiger-goat-local.1`。仅包括已发布象棋基线、虎羊本地双人和本节点必要公共依赖，不代表完整棋种或六棋种产品完成。

## 本次范围

- B型双山棋盘、开局移羊、交替摆羊/虎步、正交跳吃与可选连跳、链内禁重访、羊方强制停着、终局、悔棋和认输。
- 真实JNI、Room即时存档、离页/Activity重建恢复；独立传统菜单和显式注册备份扩展。
- 备份版本1–5兼容、真实规则准入、库存保护、恢复单事务回滚；保留schema13，不会因缺少其他棋种adapter而静默清除其数据。
- 修复Windows遗漏的上游汇编源，补齐Pikafish外部Zstandard许可正文与随包通知；搜索算法未改。

## 已验证

独立候选658文件，119项精确输入；App JVM127/127、Native门面6/6。NDK30双ABI主/仪器APK编译，Lint0错误1提醒。Android37.1 x86_64模拟器上JNI5、存储22、两档字体UI12均通过；原生规则12组、分配失败注入16项、Registry程序退出0。22张截图（14种去重画面）已检查，150%字号控件可滚动到达。ARM64仅编译，未作实体设备验收。
