# 围棋正式 AI 设置与可玩入口

源码阶段预发布，无 APK 附件，不代表完整围棋或全项目交付。

- 正式入口支持9／13／19路、执黑／执白／自动、四档和让子；真实十课及有效胜场门禁，新局保存后才进入，继续保持原规格。
- 进行中／数子局显式放弃与新建同事务；旧终局先固定并入谱。完成失败同局重试，训练、自动及未知来源不补成长。
- 接真实离线模型、Room及writer清退；返回等待资源释放。Activity重建保留同页VM，标准局重开后新UUID仍可继续；缺失活动局不隐式新建。
- 141项／14类JVM在生产与JVM输入完全相同后继承；最终APK通过74个不同设备方法／107次调用。双ABI、Lint0错误／11提醒，普通／150%共64张当前图已总览，7张关键图放大检查。
- 真实生产模型合法应答与重建已测试；脚本终局只证明规则／事务。未清应用数据，实体设备、杀进程、完整NN长局／四档强度、音效性能及最终内容仍待后续验收。
