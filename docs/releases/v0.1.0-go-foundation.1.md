# 围棋规则、搜索与离线分发基础节点

这是阶段源码预发布，不是完整围棋或全项目交付。基于已发布的象棋与虎羊节点，加入围棋可独立使用的底层能力；尚未验收的完整玩法不随本节点提前发布。

## 本次范围

- 围棋 9/13/19 路规则、让子、双确认死子结算、恢复行棋、存档与 SGF 导入导出。
- KataGo Eigen CPU 搜索、完整历史适配、访问/时间预算、取消与强持有 JNI 生命周期。
- 实际生产模型离线校验、AtomicFile 发布与缓存复核。
- 内置上游许可、模型独立许可及准确依赖源码包，许可页提供源码保存入口。
- 仅摘取必要共享契约、JNI、CMake、资源与构建配置；不纳入其他棋种正在开发的改动。

- 精确候选 1140 文件、491 个显式输入；最终标签另加四份发布/许可文档。逐文件清单见 `docs/releases/manifests/v0.1.0-go-foundation.1.json`。
- JVM 43/43；双 ABI 主/仪器 APK；Lint 0 错误、1 个既有虎羊提示。
- 原生 9 个程序在 x86_64 模拟器运行通过，含历史适配95组、真实搜索38组和运行时11组。原生源码在最终候选中完全未变，复用前一候选证据，不重复全部搜索。
- 最终 APK 实际设备测试25/25：规则3、SGF4、搜索JNI8、AtomicFile4、生产资产链2、普通/150%横屏许可页4。

## 未验收与发布边界

完整围棋入口、教程/回放/AI业务存档/自动续局/残局等后续节点不在本次范围；四档棋力、最终内容量、美术音效、API24实际设备、ARM64/实体设备运行及系统SAF真实保存流程尚未通过本节点验收。源码包复制与保存按钮回调已测试，不等于系统文档提供器写入已测试。
