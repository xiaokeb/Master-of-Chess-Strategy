# 围棋生产预算耗时诊断

Pixel 7 Pro 模拟器使用正式 KataGo 模型和现有四档预算，对三种棋盘的空盘与接触局面完成 24 次真实落子搜索。所有着手通过独立 Native 规则验证，无预算耗尽。

简单、中等和困难的 18 次搜索均低于 2 秒。大师档 6 次均超过 2 秒，范围为 4.295–6.218 秒。本次源码预发行包含诊断用例及逐步记录。实体设备时延与相邻档位棋力待验收。
