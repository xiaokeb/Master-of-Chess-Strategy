完整门禁：JVM 184/184（App 166、engine-api 5、engine-native 13），App AVD 46/46、JNI AVD 3/3；C++ 象棋规则目标在 AVD 退出码 0；Debug APK 构建通过，Lint 0 错误、3 条依赖升级提醒。

发布版本提升至 v4，使 v3 活动残局从修正后的初始局面重开；v1–v3 已完成 ID 的进度与奖励保留。实体设备音效/触控和大规模残局难度标定未由本门禁证明。
