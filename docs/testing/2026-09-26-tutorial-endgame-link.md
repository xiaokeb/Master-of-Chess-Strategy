## 测试执行注意事项

本次曾观察到逗号拼接多个类/方法的筛选命令只在报告中出现首个类；不能凭
`BUILD SUCCESSFUL` 推断列出的用例全部执行，也不能仅据此断言是配置缓存的根因。
最终按类单独执行并核对 XML 的类名、测试数与失败数，仪器测试使用
`--no-configuration-cache`。不把未列入报告的用例计为已验证。

新增测试最初的两个 Compose 测试导入错误已修正；Lint 检出的可选 Modifier
参数顺序已调整。验证只覆盖受影响教程与导航，不重复未改动的 C++ 全量、AI 棋力和内容生成测试。

横屏截图由测试生成到 `/data/local/tmp/mocs-tutorial-practice.png`，可用指定 SDK 的
ADB 拉取到 `.build/tutorial-practice.png`。测试应用卸载会清理其外部文件目录，
因此截图使用测试 shell 临时目录，不为正式应用增加存储权限。
