# 中国象棋 FEN 与自由摆局回归

## 覆盖

- 标准开局与内置原生引擎 FEN 一致；六字段解析/导出保持棋子、轮次、未吃子着数和文本回合号。
- 行宽、未知棋子、非法阵营、额外字段、越界限着计数和缺失将帅被拒绝。
- 自由摆局导入保留现有棋盘直到格式、落点与正式原生可玩性均通过；手工摆局也拒绝不可达兵、士、象。
- Android AVD 跨语言用例从 FEN 生成 MOCX，恢复第 119 个未吃子着的局面，下一着将死后胜负及再次恢复均正确。
- Compose 导航用例实际显示 FEN 输入/按钮并点击标准开局导出。
