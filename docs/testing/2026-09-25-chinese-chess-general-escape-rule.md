# 中国象棋帅应将附带捉规则验证

依据《象棋竞赛规则（2020 版）》第 26.1.2 条：帅（将）应将后附带形成的捉、杀按闲处理。本轮项目自编回归局面中，黑马原本将军红帅；红帅走开后，红车才露出对黑士的攻击。旧实现把这步记为捉，先写的原生测试在 Android x86_64 AVD 上按预期失败；修正后该着的 MOCX 历史性质为闲。

规则引擎同时修正落子时保存的历史性质及三次重复局面的扩展分析；真正将军的分类仍优先。NDK LLVM 编译的完整 C++ 规则目标在 AVD 执行退出码 0。完整 Gradle 门禁通过：JVM 183/183、App AVD 46/46、JNI AVD 3/3、Debug APK 构建成功；Lint 0 错误、3 条依赖升级提醒。此测试仅覆盖具体棋例，不宣称暗根、假根、少根和全部职业棋例已经穷尽。

规则原文：[第 26 条](https://cnchess.net/rules/ChapterSixSection26.html)。
