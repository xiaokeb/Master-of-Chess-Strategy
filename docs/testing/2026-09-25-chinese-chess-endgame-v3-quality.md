# 中国象棋残局 v3 质量门禁

## 发现与处理

v2 五个种子关卡虽能按主变化一步红胜，但在正式引擎穷举下，
第一关有 36 个立即胜着。这类局面可作为“多解胜局”演示，
不应声称为唯一解一步杀。v3 保留五关原始局面、稳定 ID、
奖励与已存进度，只修正标题和主题，并新增五个新 ID 的
“唯一一步杀”局面。

新增关卡分别为 `xq-easy-003`、`xq-easy-004`、
`xq-medium-002`、`xq-hard-002`、`xq-master-002`。
位置和讲解由项目自行设计，没有导入第三方棋谱。

## 验证

- 原生 C++ 规则测试在 Android x86_64 AVD 上逐关确认：
  初始局面未终局且黑将未受将军；遍历全部合法红着，
  恰有一着令红方立即获胜，并且该着确实将军。
- App 仪器测试加载实际 APK 资产，确认十关主变化均合法
  并在限步内红胜；对五关“唯一一步杀”穷举首着，
  确认与内容声明的主变化一致。
- v1/v2 旧进度均能在 v3 包下读取，新关采用新 ID；
  新关在独立奖励支线，旧主线仍可解锁下一难度，不会因新增关卡
  重新上锁；v2 活动残局快照从当前 v3 局面重开。
- 全量门禁：JVM 183/183（App 165、engine-api 5、engine-native 13），
  App AVD 46/46（含奖励关界面文案），JNI AVD 3/3；
  App Lint 0 错误、3 条依赖升级提醒；Debug APK 构建通过。

四档种子用于验证章节、解锁和奖励链路，尚未做职业棋力分档。
全棋种 9000+ 内容目标与实体设备音效/性能验收仍未完成。
