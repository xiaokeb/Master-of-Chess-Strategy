## 界面与边界

- 实际截图位于本地 `.build/handicap-setup.png` 与 `.build/handicap-game.png`，已检查棋盘、移除蓝圈、难度和黑方身份；右栏可滚动，不裁切棋盘。
- Android Studio Debug 静态预览新增“19 中国象棋让子设置”；不把静态预览当作 Native 验收。
- 让子沿用普通行棋规则，不引入传统让子棋额外约定。启动中全部编辑操作受保护。
- 不增加数据库列，沿用 schema 12/备份 v3；未重复运行未改变的迁移全量、C++ 或 JNI 全量。
- 正式音效复用既有链路，本轮音效资产门禁通过，不代表完成实体设备试听。
- Pikafish 和 NNUE 许可保持不变；没有新增商业授权，继续受发布清单限制。
- 象棋尚未整体验收：后台熄屏、棋力梯度、复杂棋例、内容扩充及真机性能仍需推进。
