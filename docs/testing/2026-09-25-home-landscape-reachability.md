# 横屏首页资料卡可达性回归

日期：2026-09-25。设备：Pixel_7_Pro Android AVD，横屏 3120×1440。

原画面首页左侧资料卡内容超过可用高度，底部“设置”入口被裁切，手指无法触达。宽屏布局现将资料卡固定在可用高度内并允许其内容独立滚动；窄屏布局仍滚动整页，避免嵌套滚动冲突。

模拟器上安装修复后的 APK，手势上滑后“设置”按钮进入可视区域，可点击进入设置页。App 仪器测试 50/50，包含宽屏首页滚动进入设置、模拟 600×400 dp 窄屏滚动进入设置及底部许可入口；Debug APK 构建与 Lint 通过，Lint 仍仅有 3 条依赖版本提醒。本结果不代替实体设备触控验收。
