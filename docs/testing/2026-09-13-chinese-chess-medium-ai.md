## 一致性结论

- NDK ARM64 直接构建和 Gradle 四 ABI 构建均成功，未调用 MinGW。
- C++ 测试对简单和中等返回值都验证属于当前合法着集合，且搜索前后序列化状态一致。
- Kotlin 状态机测试确认 MEDIUM 原样传入搜索，AI 应答后仍轮到红方。
- 路由使用稳定编码 1 表示 MEDIUM；未知及尚未实现难度不能从 UI 或快速进入绕过。
- Debug 原生库保留调试符号并原样打包，不影响 Debug APK 生成。
