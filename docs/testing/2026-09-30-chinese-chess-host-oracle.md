# 中国象棋残局主机端独立浅层校验

日期：2026-09-30。为在不运行设备端测试时继续检查内容质量，新增纯 Python 的浅层象棋走法、将军、将死/困毙与一、两次红方走子强制胜穷举。此实现与 NDK 正式规则引擎分离，作为候选筛查和交叉核验，**不替代正式规则裁判**。

## 已核对的发布包

对 `endgames-v5.txt` 的 16 关逐关检查主变化合法且以红胜终局；五关多解演示各有多个获胜首着，九关“唯一一步杀”各有且只有一个获胜首着，两关“两步强制胜”均无一步胜着、且有唯一可抵御全部黑方应手的首着。主机端本次遍历计数 5426，仅是该独立实现的计数，不与 NDK 证明节点数混同。包内容和 SHA-256 未改，镜像等价后仍为 15 个独立局面。

暂存工具现在除了校验生成器输出结构，还独立穷举候选首着、核对主变化、一步杀的将军要求及两步题不存在一步胜着。若预算耗尽、结果不唯一或首着与主变化不符，候选不会通过暂存；通过仍只标记 `staged-not-published`。

## 验证与限制

- Conda 全部 Python 离线单测 50/50；可独立运行 `python tools/python/verify_xiangqi_forced_win.py` 复核当前发布包。
- 覆盖基础棋子走法、蹩马腿、炮架、将帅照面、自陷将、将死和困毙；不覆盖三次重复、长将/长捉、自然限着、深层难度与逆向可达性。当前只接受一、两次红方走子的主题，预算耗尽明确为未知。
- 本节点不新增发布题、无设备端原生或界面测试；后续入包仍需 NDK 正式规则证明、逐题人工审核、来源/授权清单和发布构建门禁。
