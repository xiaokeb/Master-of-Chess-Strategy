# 围棋与国标麻将的无障碍状态

围棋继续为每个交叉点提供独立描述。回放、保存等禁止操作的页面状态现在也会将交叉点标为禁用。盲棋仍在行棋期间隐藏棋色，诊断使用实际生产盲棋入口。

国标麻将牌面保留原画面，Android 无障碍树由牌本身提供名称。牌面的短文字以及牌背上的「纹」不再成为额外的朗读目标。暗牌只提供「牌背」说明，即使渲染层收到暗牌编号，也不通过文本或描述暴露它。

## 验收

Pixel 7 Pro 模拟器通过 7 次测试。Android 无障碍树核对了九、十三、十九路各落点的实际焦点边界、点击动作与禁用状态，并验证国标明牌只有一个可朗读名称，暗牌只暴露「牌背」。通过两档字号的围棋盲棋和国标正式赛事回归，核对盲棋续局、终局显示、麻将实际出牌和存档续局。共检查 18 张截图。

11 项 JVM、NDK 30 双 ABI、Debug 主 APK、测试 APK 和 Release 主清单通过。Lint 0 错误、25 警告。实体设备和 TalkBack 实际语音待验收。
