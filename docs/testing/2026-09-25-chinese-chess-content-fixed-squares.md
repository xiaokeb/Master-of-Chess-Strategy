# 中国象棋残局固定落点门禁

## 问题与修正

此前内容审核只检查兵卒出生行、士的九宫范围、象是否过河，可能接受未过河却横移到奇数列的兵卒，或处在斜行轨迹以外的士、象。新增红黑双方六类非法样例，修正前在 Python 离线测试复现六项失败。

Python 生产审核器与 Android 资源解析器现共用相同的摆位约束口径：未过河兵卒留在出生偶数列，士限九宫内五个可达交叉点，象限本方七个可达交叉点。另有六类合法正例防止误拒。该门禁只检查单枚棋子的必要条件，不能证明整个局面可由标准初始局面到达，也不代替 NDK 主变化验证、唯一性审核或授权审查。
