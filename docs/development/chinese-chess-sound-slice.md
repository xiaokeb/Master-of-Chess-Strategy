# 中国象棋正式音效

## 目标

让既有音效设置真实控制中国象棋的落子、吃子和终局反馈，同时保持纯离线、低延迟和页面生命周期安全。

## 事件与播放

| 事件 | 音效 |
| --- | --- |
| 普通合法着 | chess_move.wav |
| 吃子合法着 | chess_capture.wav |
| 玩家胜利或本地/自动演局分出胜负 | game_victory.wav |
| 人机模式玩家失败 | game_defeat.wav |
| 和棋 | game_draw.wav |

ViewModel 通过 replay=0 的 SharedFlow 发送实时事件。恢复存档、Compose 重组和重新进入页面不会重放旧动作；缓冲满时丢弃最旧音效，不阻塞走子或持久化。

页面使用 SoundPool 播放短音频，最多同时播放两路。采样异步加载时只保留最新待播事件；页面退出后立即释放播放器。音效关闭时事件直接跳过，重新开启不补播。

## 资源

五个文件均由 tools/audio/generate-chinese-chess-sounds.ps1 确定性生成，为 22,050 Hz、单声道、16 位 PCM WAV，不包含第三方录音。每次 preBuild 校验文件长度和 SHA-256，避免资源被静默替换或损坏。

## 边界

当前只消费中国象棋事件。其他棋种接入时复用事件/播放器模式，并使用各自操作语义的资源；设备试听、媒体音量和厂商音频栈行为需在设备或 AVD 可用后验证。
