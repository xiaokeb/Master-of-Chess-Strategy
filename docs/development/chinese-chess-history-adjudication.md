# 中国象棋历史裁定核心

## 目标

在基础走法之外保存可撤销的完整局面历史，为三次循环、单方长将、直接无根子长捉、允许着法循环和 60 回合自然限着提供确定性裁定。

## 规则口径

采用中国象棋协会审定《象棋竞赛规则（2020 版）》：

- 第 23.1：双方着法循环反复三次形成重复局面。
- 第 23.5.1：单方长将判负。
- 第 24.6、24.8：拦属于闲，兑、献、拦、跟均在闲着范围。
- 第 24.9、24.11：长将和长捉均以循环三次为基础。
- 第 26.9：单方禁止着法应变，双方允许着法不变作和。
- 第 4.2.4：连续 60 回合未吃子符合自然限着和棋条件。

原始项目文档把“长拦等重复局面直接判进攻方负”作为简写，与上述正式条款冲突；引擎不采用该简写。

## 状态与裁定

1. position_history_ 保存每步后的棋盘和行棋方，使用完整状态比较，不以可能碰撞的哈希单独裁定。
2. MoveRecord 保存走子、被吃子、上一步计数与裁定结果、着法性质，支持裁定后悔棋。
3. 每步先分类为将、直接无根子捉或闲，再查找当前完整局面的最近三次出现。
4. 单方所有循环着均为将时该方负；单方所有循环着均为将/捉而对方不是时，攻击方负；其余当前覆盖的允许循环判和。
5. 每个未吃子着使自然限着计数加一，吃子归零；达到 120 着即 60 回合时判和。
6. 已终局后引擎拒绝继续行棋；悔棋恢复此前计数与裁定。

## 长捉边界

当前自动长捉识别采用保守的直接无根子子集：

- 排除帅将、兵卒自身允许的长捉。
- 捕获必须是合法着且不造成己方自杀。
- 若被捉子被吃后，对方存在立即合法回吃，则视为有根，不判直接无根子捉。
- 只有本着新增的无根子威胁才标记为捉。

杀着、联合捉、暗根、假根、少根、不同价值交换以及连续追捉同一棋子集合，必须按官方棋例图例继续扩展，当前节点不宣称覆盖职业裁判全部案例。

## MOCX 2

MOCX 2 保存：

- 魔数、格式版本、显式 GameType 和当前方。
- 自然限着计数、历史裁定结果和历史条数。
- 当前 90 点棋盘及可逆走子记录。
- 末尾 CRC32，任何负载单字节损坏均在解析前拒绝。

历史最多 4096 着，最大编码仍低于 App Repository 的 64 KiB 边界。MOCX 1 不含历史和校验和，按不兼容快照定向清理并从标准局面恢复，不做有损伪迁移。
