# 棋种独立集成与发布：实施计划

依据用户的单棋种节点发布决定、AGENTS 及现有完整产品要求。Root 串行负责公共接口、构建、Git/tag/Release；专属任务并行不修改公共文件。当前已发布音效 tag 保持；虎羊本地双人在混合工作区通过，精确候选源码尚待验证。

## 采用方案

固定共享 Room schema，正式解耦传统菜单与备份扩展注册。不创建按棋种变化的 schema，不删除已实现玩法，不缩掉虎羊存档/备份/导航以换取较小发布。完整开发版本仍注册目前所有已接入功能；单节点候选只注册实际包含的功能，不显示缺路由的可点击入口。

## 1. 菜单注入

新增共享 TraditionalGameMenuEntry：稳定 id、label/testTag、按钮样式、onClick。公共 LanzhouTraditionalModesScreen 只渲染传入条目，不引用方棋 Difficulty、专属路由或资源。Root NavHost 按原顺序注入方棋本地/四档 AI 和虎羊条目，保留标签、文案和操作行为。共同标题/返回资源独立于专属棋种。

先写条目唯一性/顺序/回调测试，补单棋种菜单不暴露未注册入口的 Compose 测试，再改公共组件与唯一调用点。重验传统导航及虎羊真实导航，普通/150%菜单视觉；无需重复原生规则/OOM/JNI测试。修改前显式解冻共享菜单/App 两项，更新对应源码清单和新证据，旧 10 月 13 日收据只说明迁移前版本。

## 2. 备份扩展注册

新增 GameBackupAdapter / GameBackupRegistry：不可变、防御复制载荷、固定注册快照、recordKind/最低版本/归属槽、读取/编码/解码/Native准入/事务写入。拒绝重复注册、错误归属和越限数据，不用无约束 Any。

分别把虎羊与国标专属 archive/准入/记录处理放到各自 adapter。公共 Snapshot/Codec/Repository 不再静态实例化棋种 Native 引擎；Root 组装处显式注册当前全部 adapter。所有测试/工厂直接构造 Repository 的调用点明确注册，不能默认空注册而静默改变生产行为。

保留完整版本 v1–5 语义、无虎羊输出 v4、有虎羊输出 v5、既有记录字段/顺序/限额、重复拒绝、坏档保留旧库、旧备份全量替换、同事务快照及清表前实际 Native 准入。恢复在一个 Room 事务内写所有数据，SQL 失败全回滚；writer cancel/join 屏障不变。

缺 adapter 必须 fail-closed：输入未知记录拒绝；数据库已有未注册槽数据时导出/全量恢复拒绝，不漏导、不清表。公共数据层枚举已知 schema 全部槽；恢复事务内清表前再次检查非空未知槽，避免时间差。保持 schema13、国标 entity/DAO、MIGRATION_12_13 和 schema JSON，不升级14、不回退12、不 destructive migration。

先写缺 adapter 输入/目标非空、重复注册、注册顺序不改编码、归属与限额红测试。再迁移并运行基础/虎羊/国标/混合 codec、v1–5往返，虎羊磁盘备份5项及受影响国标真实Room/迁移/SQL回滚、旧writer屏障；不把历史81项直接套用到迁移后版本。

## 3. 精确候选源码验证和发布

从基线 HEAD 与审查后的专属源码/共享片段形成明确 tree/index 清单，导出仓库 `.build` 下独立源码快照；不是 worktree，不覆盖主工作区。核对 typed Registry release、独立 JNI、CMake、Home测试标签、资源、schema、许可及未解析引用。

分别验证完整注册版本与仅已发布 adapter 的候选版本。必要的定向JVM、双ABI NDK、Lint、APK、实际模拟器/视觉通过后，显式暂存并核查差异，提交、推送附注tag及prerelease。产物只能来自实际标签源码；未验证文件、其他对话在改文件和混合APK不带入。发布记录写范围、测试、未验事项、来源、提交/tag/链接。

## 并行象棋轨道

原 production-v4r1 hard-master 13局完整前缀、无汇总，原散列保持。第14局为零基 index13、opening7 strong_side1，后缀35局；冻结基准不支持该续测参数。另行预注册追加续测协议，明示源码/新二进制身份、固定输入和未变的搜索/裁判语义，保留旧文件，独立合并审核与逐着回放；不能重启原 CreateNew 组或冒用 suite3 历史锁。master 使用1200ms墙钟搜索，不能承诺重启后逐着等于未中断的反事实。前缀没有耗时汇总，仅报告35局后缀实测延时与48局分段胜负/删失审核，不伪造48局正常汇总或全局延时。前两组1.0/.96875不符合约7:3梯度，不因续测调整参数或挑开局。

本计划是已授权正常开发的公共边界整顿，不要求用户重复授权；许可扩大、数据破坏、真实产品冲突或重要外部操作超出已有授权时再询问。完整六棋种目标保持，实体/内容量/AI梯度分列，不以本节点通过宣称全项目完成。
