# 本地备份逐行读取

恢复仍按原有 MOCS-BACKUP 格式读取。校验器在输入字节数组上核对正文 SHA-256，随后逐行严格解码 UTF-8，保留旧版允许的空行。校验尾行、LF 换行、最大 128 MiB、20 万条非空行、各棋种记录验证及事务边界沿用原有要求。

读取阶段省去整份 UTF-8 文本、正文副本及全部行字符串列表。系统文件输入仍会读入一个字节数组，解析后的记录仍需等待验证及写入。128 MiB 测试使用带旧格式空行的合法备份；真实大档案导入的峰值内存和实体设备性能需另行测量。

## 验收

42 项 JVM 通过，包括恰好 128 MiB 的解码夹具、正确校验和下的非法 UTF-8 和回车、旧格式及混合棋种扩展。NDK 30 双 ABI、Debug 主 APK、测试 APK 和 Release 主清单通过，Lint 0 错误、25 警告。

Pixel 7 Pro 模拟器通过 3 项生产备份回归。围棋从设置页导出、恢复、取消及拒绝无效文件，恢复后重新打开并继续保存。普通字号的 6 张画面核对了设置反馈与棋局。国标麻将使用新版 WMO 规则，完整十六盘档案经生产备份导出与恢复后验证逐盘证据。
