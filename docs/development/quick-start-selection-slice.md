# 上次模式与首页快速进入纵切

## 目标

保存每个棋种最后一次成功选择的模式与难度，并在首页存在可信历史时提供长按快速进入。普通点击始终进入模式选择，不改变首次使用路径。

## 数据边界

- last_game_selections 与 active_games 分表：导航偏好不解析、不覆盖规则引擎 BLOB。
- 棋种、模式和难度均保存稳定整数编码；未知编码或无效组合返回 Incompatible。
- 本地双人、残局和教程不得携带难度；人机和 AI 演局允许保存难度。
- 每个 GameType 最多一行，更新时间用于后续多入口排序或诊断。
- Room schema 从 1 显式迁移至 2，只新增表，不删除或重建既有活动对局。

## 交互规则

1. 应用启动时异步读取中国象棋的上次选择。
2. 无记录、读取失败或不兼容时不暴露首页长按动作；不兼容行会定向清除。
3. 普通点击中国象棋仍进入模式页。
4. 选择本地双人后记录模式并进入对局；选择普通人机后记录模式并进入难度条件页。
5. 首页长按按当前能力边界路由：本地双人进入对局，普通人机进入难度页，尚未开放的历史模式退回模式页，不绕过解锁。
6. 元数据保存失败不阻断当前导航，也不会把失败记录暴露为可信快速入口。

## 并发约束

应用级 AppNavigationViewModel 持有选择状态。用户新选择会递增本地修订号，启动时尚未完成的旧查询不得覆盖新选择；只有保存成功的选择才更新快速入口。

## 版本

- 当前 Room schema：3；上次选择表由 schema 2 引入，schema 3 仅新增设置表。
- 迁移：1 → 2，显式无损迁移。
- 上次选择表：last_game_selections。
