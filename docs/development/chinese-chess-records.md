# 中国象棋棋谱节点

## 功能范围

- 所有完成的本地双人、人机、AI 自动演局和残局对局按对局 ID 自动保存，重复终局通知不会产生重复记录。
- 棋谱页提供全部对局、精彩收藏、残局棋谱三类筛选。
- 回放复用正式象棋棋盘，支持首步、上一步、下一步、末步、0.5× 至 4× 自动播放。
- 用户通过 Android 系统文档选择器明确选择位置后导出，不申请存储权限。
- 导出格式为 UTF-8 JSON，包含格式版本、模式、难度、结果、回合数、引擎状态十六进制数据及 SHA-256，可检测状态损坏。

## 数据边界

Room schema 8 新增 game_records。终局引擎状态上限 64 KiB，回合数上限 10000；结果必须为终局，残局标记只能与 ENDGAME 模式同时出现。收藏只更新独立布尔字段，不覆盖不可变终局载荷。

回放不会保存大量重复棋盘快照。读取时恢复最终引擎状态，逐步撤销并反转所得棋盘序列；实际历史帧数必须严格等于已记录回合数加一，否则拒绝显示该棋谱。引擎在成功、失败和不兼容路径均关闭。

## 验证

- 仓库测试覆盖幂等插入、筛选、收藏、损坏版本拒绝和字节数组防御性复制。
- ViewModel 测试覆盖终局只通知一次、列表刷新、回放顺序、历史回合数一致性和原生资源关闭。
- 导出测试固定格式版本、JSON 转义、状态内容与 SHA-256。
- Android UI 测试源码覆盖首页至棋谱列表导航；真实设备交互仍受当前无设备/AVD 条件限制。
