# 中国象棋棋谱节点

## 功能范围

- 所有完成的本地双人、人机、AI 自动演局和残局对局按对局 ID 自动保存，重复终局通知不会产生重复记录。
- 让子对局也保存独立模式、难度及玩家身份；保存棋谱不等于排位结算，不产生正式胜场、积分或难度解锁。
- 棋谱页提供全部对局、精彩收藏、残局棋谱三类筛选。
- 回放复用正式象棋棋盘，支持首步、上一步、下一步、末步、0.5× 至 4× 自动播放。
- 用户通过 Android 系统文档选择器明确选择位置后导出，不申请存储权限。
- 导出格式为 UTF-8 JSON v2，包含玩家索引、模式、难度、绝对结果、回合数、引擎状态十六进制数据及 SHA-256，可检测状态损坏。
- 设置页可独立开启三种精彩局自动收藏条件，默认均关闭，仅对 AI 自动演局和指定开局自动演局生效；命中任一条件即标记现有终局棋谱为收藏，不另建重复记录。

## 精彩局条件

- 逆转局：获胜方在对局中因被吃子出现过至少 500 子力分的劣势（相当于一车），随后获胜；仅按棋子价值和 MOCX 吃子历史计算，不声称使用引擎胜率或优势评估。损坏或不兼容状态不据此收藏。
- 大师局：难度为大师的自动演局，无论胜负或和棋。
- 长局：达到 160 个有效半回合的自动演局，无论胜负或和棋。

条件只在终局首次保存时判定。之后修改设置不会追溯改变历史收藏；手动收藏与取消收藏仍独立可用。

## 数据边界

Room schema 8 新增 game_records；schema 11 在设置表增加精彩局条件位掩码，旧用户默认全关。终局引擎状态上限 64 KiB，回合数上限 10000；结果必须为终局，残局标记只能与 ENDGAME 模式同时出现。收藏只更新独立布尔字段，不覆盖不可变终局载荷。

Schema 12 在棋谱中保存玩家索引（0 红、1 黑），旧记录默认为红方；标题显示玩家
身份，回放保留原执子视角。AI 先手不会交换棋谱中的红黑绝对结果。

回放不会保存大量重复棋盘快照。读取时恢复最终引擎状态，逐步撤销并反转所得棋盘序列；实际历史帧数必须严格等于已记录回合数加一，否则拒绝显示该棋谱。引擎在成功、失败和不兼容路径均关闭。

## 验证

- 仓库测试覆盖幂等插入、筛选、收藏、损坏版本拒绝和字节数组防御性复制。
- ViewModel 测试覆盖终局只通知一次、列表刷新、回放顺序、历史回合数一致性和原生资源关闭。
- 导出测试固定格式版本、JSON 转义、状态内容与 SHA-256。
- Android UI 测试覆盖首页至棋谱列表导航及精彩局条件开关；模拟器测试不能代替实体设备验收。
