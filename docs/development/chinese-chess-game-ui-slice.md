# 中国象棋对局 UI 纵切

## 目标

把已经验证的 NativeChineseChessEngine 接入首个可操作的横屏对局页，形成选子、合法落点、走子、悔棋和重开的端到端闭环。

## 边界

- 本节点是本地双人基础对局，不引入 AI、联网、计时、成长结算或持久化。
- 长将、长捉、长拦和自然限着继续按规则规格延期。
- ViewModel 独占并释放一个规则引擎会话；Compose 不直接调用 JNI。
- UI 状态是 90 个交叉点的不可变快照，不持有原生句柄或可变棋盘。
- 原生异常转为稳定的不可用状态，不向页面暴露路径或底层错误文本。

## 交互

1. 默认红方先手，点击己方棋子显示合法落点。
2. 点击另一枚己方棋子切换选择，重复点击已选棋子取消选择。
3. 点击合法落点执行走子并刷新棋盘、行棋方和终局状态。
4. 空点、对方棋子和非法目标给出简短反馈。
5. 悔棋仅在本会话已有成功走子时可用；重开恢复标准初始局面。
6. AI、提示和其他尚未具备业务支撑的按钮保持禁用并明确标注。

## 验证

- ViewModel 单元测试使用内存规则引擎替身，不加载 JNI。
- Compose 仪器测试验证棋盘、控制区与禁用能力的语义。
- 受影响模块执行 JVM 测试、Lint、Debug 构建和 Android 测试 APK 编译。

## 后续补充：将军提示

规则引擎经 JNI 暴露指定阵营是否被将军；ViewModel 仅查询当前行棋方，并随走子、悔棋、恢复重新生成状态。非盲棋棋盘在被将军的将帅外绘制警示圈；状态区和无障碍描述同时明确受将军方。盲棋保留文字告警，但不暴露将帅落点光圈。终局胜负提示优先于将军提示。
