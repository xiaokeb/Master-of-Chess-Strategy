# 中国象棋棋力评测

## 正式规则

棋力评测是五局本地定级赛。玩家执红，从中等 AI 开始；每局胜利后下一局提升一级，失败后降低一级，和棋保持当前难度，简单和大师分别为上下界。评测可调用全部四档 AI，但不会改变普通模式的难度解锁。

初始评分为 1200，最终限制在 400–2400：

| 对手 | 胜局加分 | 负局扣分 | 和棋 |
| --- | ---: | ---: | ---: |
| 简单 | 100 | 400 | 0 |
| 中等 | 200 | 300 | 0 |
| 困难 | 300 | 200 | 0 |
| 大师 | 400 | 100 | 0 |

评测全程禁止提示和悔棋。每局仍可认输、提和，并使用正式棋钟和音效；终局只能进入系统计算的下一对手，不能用普通重开绕过系列状态。第五局结束后展示最终评分和胜/和/负记录，新评测须返回设置页显式开始。

## 数据边界

- 稳定模式编码为 `ASSESSMENT_CHALLENGE = 9`。
- 会话变体为 `assessment:<已完成局数>:<评分>:<胜>:<和>:<负>:<阶段>`。
- 阶段 `n` 表示当前局进行中，稳定难度码表示终局后待进入的下一局，`f` 表示五局完成。
- 已完成局数必须为 0–5，胜和负之和必须相等，评分必须为 400–2400；前导零、未知阶段、未知难度及非规范文本全部拒绝。
- 进程恢复以 Room 快照中的实际对手难度和系列状态为准，不依赖旧导航参数。

## 业务复用

评测复用正式 C++ 规则引擎、四级本地 AI/Pikafish、双方棋钟、提和、认输、活动存档、MOCS-BACKUP、SoundPool 音效和棋谱。每局按实际对手难度生成专项棋谱，但不写标准人机胜负账本，不改变首页胜场、积分或普通难度解锁。

## 界面

设置页说明五局、升降级和评分公式，并提供新评测或继续有效系列。对局控制区显示当前局次、评分、胜和负以及下一对手；系列进行中和完成后均不提供普通重开。
