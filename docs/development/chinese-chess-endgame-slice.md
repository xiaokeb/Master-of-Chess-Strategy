# 中国象棋残局节点

更新时间：2026-09-19

## 已实现

- 版本化离线残局包、严格解析器和 MOCX v2 自定义局面编码。
- 简单至大师四档章节、关内线性解锁、完成整档后解锁下一难度。
- 主线、主题、按本机日期稳定选择的每日残局和仅从已解锁关卡抽取的随机挑战。
- 指定步数内红方取胜的通关判定；耗尽玩家步数且未获胜立即判挑战失败，
  不再触发 AI 应答。
- Room schema 9 保存稳定关卡 ID、最佳玩家步数、首通星级/积分和完成时间。
  `INSERT IGNORE` 保证首通奖励只发一次，重复挑战只允许改善最佳步数。
- 首页汇总对局成长与残局奖励；终局继续进入棋谱库并标记为残局棋谱。
- 模式页、快速进入、目录、关卡路由、残局目标提示、音效和 Android Studio
  Debug 预览已接通。

## 内容与法律边界

内置 v1 为项目自编的 5 关功能种子包，覆盖四档难度并用于验证完整业务链，
不冒充最终 9000+ 内容库。种子包声明 GPL-3.0-or-later，未复制外部棋谱注释
或来源不明的残局数据。未来扩充必须按
`config/schemas/chinese-chess-endgame-pack-v1.md` 保存逐批许可证据。

残局对局仍通过同一个中国象棋规则引擎验证合法着；大师难度继续调用已固定
版本的 Pikafish 和 NNUE。Pikafish 程序、对应源码、GPL 文本、修改记录及
NNUE 独立使用限制沿用项目现有发布门禁，本节点未放宽任何许可边界。

## 测试边界

JVM 测试覆盖格式拒绝、CRC32、解锁链、每日稳定性、随机候选、首通幂等、
最佳步数和对局限步结算。C++ 测试目标包含正式种子包 5 个局面的恢复、合法
着和一步将死断言。

当前没有设备或 AVD，故 Compose/Room/JNI 仪器测试只完成源码编译与 APK
打包；NDK C++ 测试目标只在指定 Android NDK LLVM 下完成编译和链接，不能
在 Windows 宿主机直接运行。不得把这两项描述为设备运行通过。
