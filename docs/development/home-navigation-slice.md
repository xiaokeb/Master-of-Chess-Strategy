# 首页与模式导航纵切

## 目标

建立正式单 Activity Compose Navigation 返回栈，让用户从五张棋种入口卡进入中国象棋模式选择，并进入已经完成的本地双人对局。

## 页面流

1. 首页按 40/60 分栏展示本地档案摘要和五张棋种入口卡。
2. 中国象棋进入模式页；本地双人进入对局，普通人机进入难度页。
3. 难度页按教程与胜场规则展示四档解锁条件，当前全部锁定。
4. 系统返回与页面返回按钮均使用同一导航返回栈。
5. 对局 ViewModel 绑定对局目的地，离开目的地时释放原生会话。

## 边界

- 本节点不伪造教程完成、胜场、段位或 AI 能力。
- 围棋、麻将和兰州特色棋展示为后续切片，不能进入空页面。
- 首页统计使用明确的本地初始状态，持久化在下一节点实现。
- 长按快速进入依赖“上次模式”持久化，本节点不提前实现。

## 依赖

使用稳定版 androidx.navigation:navigation-compose:2.10.1；该版本最低 API 24，与项目 minSdk 一致。
