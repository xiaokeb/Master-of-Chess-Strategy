# 中国象棋自由摆局

## FEN 导入与导出

自由摆局支持粘贴六字段 Pikafish 风格 FEN（棋盘、`w/b`、`- -`、连续未吃子着数、完整回合号），并可将当前局面生成规范 FEN、复制到系统剪贴板。棋盘自上而下为黑方至红方，红子使用大写 `KABNRCP`，黑子使用小写。导入先做字段、行宽、棋子与将帅数量检查，再检查固定落点、棋子上限、将帅照面，最后通过正式原生规则引擎确认对局仍可进行；失败时保留原棋盘。

导入时的连续未吃子着数写入 MOCX，限着规则继续生效。FEN 完整回合号在摆局页面保留并可原样导出，但不是 MOCX 的历史步数；开始新的自由摆局后，从该局面重新计步，不能凭一个 FEN 伪造此前的循环历史。手工编辑棋子或改先行方会清零限着计数并重置展示回合号。

## 功能边界

自由摆局位于中国象棋扩展玩法目录。用户可从标准局面开始编辑，也可清空棋盘，选择红方或黑方棋子、橡皮、先行方及当前已解锁的 AI 难度。扩展目录只开放已经具备正式业务和测试边界的玩法。

## 局面校验

- 每方棋子不得超过标准数量，双方各有且仅有一个将或帅。
- 将帅只能位于本方九宫，士仕与象相须处在各自可达的固定落点；未过河兵卒须留在出生列。将帅不可无子相隔照面。
- 编码采用现有 MOCX 稳定状态格式。开始前由正式中国象棋引擎恢复该状态，并确认结果仍为进行中且至少存在一个合法着。
- 局面非法、已经终结、无合法着或原生引擎不可用时不创建对局，并显示稳定错误文案。

## 对局与数据

活动会话模式使用稳定编码 `CUSTOM_POSITION = 5`。会话变体为 `custom:` 加原始 MOCX 状态的小写十六进制，最大 128 字节；解码后必须能够规范往返。当前对局状态仍保存于独立引擎 BLOB，因而重开可回到原始摆局，进程恢复可回到当前进度。

对局复用正式 AI、双方棋钟、悔棋、提示、提和、认输、音效和棋谱链路。自由摆局终局会保存棋谱，但不写入排位胜负账本，不影响难度解锁。备份恢复会分别验证当前状态和原始摆局，任何一个状态无效都会拒绝整个恢复事务。

## 界面验收

Debug 预览目录提供“09 中国象棋自由摆局”。正式页面使用与对局相同的棋盘绘制，横向滚动的棋子工具避免小屏横屏溢出；继续上次自由摆局只在活动会话和原始状态均有效时显示。
