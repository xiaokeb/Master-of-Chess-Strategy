# 本地设置纵切

## 目标

提供可从首页和对局页进入的正式设置页面，统一管理默认难度、自动续局、音效和对局时长，并通过 Room 自动持久化。

## 默认值与范围

| 设置 | 默认值 | 有效范围 |
| --- | --- | --- |
| 默认难度 | 简单 | 简单、中等、困难、大师 |
| 自动续局 | 关闭 | 开启或关闭 |
| 音效 | 开启 | 开启或关闭 |
| 对局时长 | 不限时 | 不限时，或 5–180 分钟 |

启用时限时从 30 分钟开始，以 5 分钟步进调整。默认难度只为已解锁的人机模式提供默认选择，不改变教程和胜场解锁条件。

## 数据边界

- app_settings 使用固定主键 0 保存单行完整设置，更新一次提交整行，避免字段间出现半更新状态。
- Room schema 从 2 显式迁移至 3，只新增设置表，保留活动对局和上次模式表。
- 未知难度、越界时长或读取失败不会进入 UI；页面恢复安全默认值并给出明确状态。
- 保存期间禁用设置控件，避免并发写入由旧值覆盖新值；保存失败回滚到上次内存状态。
- 所有数据保留在本地，不新增联网权限。

## 页面与消费边界

- 首页本地档案区提供设置入口；中国象棋对局顶部也提供设置入口。
- 对局顶部即时展示“不限时”或配置分钟数。
- 当前节点完成偏好保存与展示。AI 自动续局、实际音效播放和超时判负必须由对应业务能力显式消费，不在设置页伪实现。
