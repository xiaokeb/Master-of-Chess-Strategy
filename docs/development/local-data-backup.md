# 本地数据备份与恢复

## 目标

设置页提供用户主动触发的完整本地备份与恢复。流程只使用 Android
系统文档选择器，不申请存储权限、不上传云端，也不新增网络权限。

## 文件与数据边界

- 文件头为 MOCS-BACKUP 版本 1，采用规范 UTF-8 与 LF 换行。
- 文件尾保存 SHA-256；恢复时先验证大小、编码、版本、字段、主键唯一性和
  校验和。
- 当前备份覆盖活动对局、上次选择、设置、教程进度、胜负账本、棋谱和残局
  进度。
- 中国象棋活动对局和棋谱在恢复前逐条交给当前 NDK 规则引擎试恢复；自由
  摆局还会同时验证会话变体中保存的原始局面。引擎拒绝的状态不会写入数据库。
- 残局进度必须引用当前 GPL 内容包内的关卡，并匹配难度、步数上限和固定
  奖励。内容版本不兼容时拒绝恢复，不猜测迁移。
- 单文件最大 128 MiB。未知记录、重复主键、越界计数和非终局结果均拒绝。

## 原子恢复

解码、完整性验证、引擎验证和残局引用验证全部发生在数据替换之前。通过后，
Room 在单个事务内清空并重建七类本地表；任何写入失败都会回滚。成功后重建
Activity，使所有应用级 ViewModel 从数据库重新读取，避免展示恢复前缓存。确认
恢复时先清理首页之上的导航栈，释放潜在的对局 ViewModel 和后台任务，防止旧
会话在恢复事务之后再次写回。

系统文件选择器返回空 URI 时视为用户取消，不修改状态。导出或恢复失败只显示
稳定错误文案，不向界面泄露文件路径或底层异常。

## 扩展约束

备份版本 1 只允许当前已正式落地的中国象棋引擎状态。其他棋种接入持久化后，
必须先定义其稳定状态版本和恢复验证器，再升级备份格式；不得把未验证的任意
二进制直接写回 Room。
