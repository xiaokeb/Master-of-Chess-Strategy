## 已验证

- JVM 单元测试：183 个通过，0 失败、0 错误、0 跳过。
- NDK：Clang 21，C++17，Android ARM64 目标编译链接通过；x86_64 C++ 象棋规则目标在 AVD 运行通过。
- Gradle NDK：arm64-v8a、x86_64 两个正式 64 位 ABI 构建通过。
- Android：Pixel_7_Pro AVD 上 App 46/46、engine-native JNI 3/3；App Lint 0 错误、3 条依赖升级提醒；Debug APK 构建通过。
- 离线边界：Debug APK 不包含 android.permission.INTERNET。
- 大师资产：NNUE 大小和 SHA-256 构建校验通过，APK 同时包含权重、许可文本和两套完整原生引擎库。

## 条件限制

模拟器验证不等于实体设备验收：触控手感、音效试听、媒体音量、Pikafish
大师模式耗时及长局性能仍需在实体设备确认。C++ 构建由 CMake 强制要求
Android NDK 工具链，不接受 MinGW 或宿主机工具链。
