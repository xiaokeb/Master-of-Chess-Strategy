# 中国象棋教程与简单难度解锁纵切

## 目标

提供可恢复的新手教程闭环，并只在用户完成全部教程检查点后解锁中国象棋简单难度。阅读、练习和测验页不创建原生活动对局；完成后可主动进入对应的正式练习残局。

## 教程流程

| 步骤 | 内容 | 完成条件 |
| --- | --- | --- |
| 目标与胜负 | 红先、轮流行棋、将死与困毙 | 阅读后继续 |
| 七类棋子 | 车、马、炮、相、士、将帅、兵卒的入门规则 | 阅读后继续 |
| 交互练习 | 将红兵从 (0, 6) 前进一步至 (0, 5) | 先选红兵，再走到唯一合法目标 |
| 知识测试 | 无将军但无合法着法的裁定 | 选择“该方负（困毙）” |

教程完成页明确区分入门规则和后续复杂裁判棋例，不把一次教学练习描述为完整规则训练。

## 对应练习残局

- 完成页提供“练习残局：双马锁宫演示”，对应稳定 ID `xq-easy-001`，练习一步取胜与棋子配合；明确提示这是多解入门题。
- 仅在教程完成检查点已保存、残局目录已加载且该关按正常规则解锁时启用；保存中、保存失败回滚、目录缺项或关卡锁定均不能通过新入口进入。
- 点击时再次检查条件，使用既有残局导航和单实例跳转，不创建另一套教学裁判或奖励表。
- 练习复用正式残局的活动对局槽、Native 规则、AI、音效、存档、棋谱和首通奖励；对局返回按钮回到教程完成页，而不是跳到主页。
- 与其他正式残局入口相同，进入不同模式/变体会按既有规则切换象棋活动会话；本入口不新增并行存档能力。
- 原有教程内容版本 1、四个检查点和数据库 schema 11 均不变；已完成教程的用户无需重学即可使用新入口。

## 数据与一致性

- tutorial_progress 按 GameType 单行保存内容版本、已完成步骤数、完成标记和更新时间。
- Room schema 从 3 显式迁移至 4，只新增教程表，保留活动对局、上次模式和设置。
- 当前教程内容版本为 1，共 4 个检查点；完成标记必须与步骤数 4 完全一致。
- 未知内容版本、越界步骤或完成状态矛盾均视为不兼容，只清理对应棋种的教程进度。
- 每个检查点单次写入；保存期间禁用交互与返回，失败时回滚到前一步并允许重试。

## 导航与解锁边界

- 中国象棋模式页正式开放教程入口，上次选择为教程时首页长按可直接返回教程。
- 教程 ViewModel 位于应用导航作用域，完成后返回难度页即可看到最新解锁状态。
- 只有简单难度由教程完成状态解锁。
- 中等、困难和大师分别依赖真实的前级胜场，不能由教程练习入口越级解锁。
- 简单难度已接入正式 AI 对局；未完成教程时仍不可选择或快速进入。

## 实现边界

交互练习验证教程规定的单一目标动作，不在 Kotlin UI 中复制 C++ 完整规则引擎。后续练习若需要任意合法走法，应通过规则引擎提供的正式教学会话完成。
