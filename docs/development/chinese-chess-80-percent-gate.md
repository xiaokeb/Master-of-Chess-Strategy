# 中国象棋 80% 历史复核（启动门槛已作废）

旧口径复核日期：2026-09-30。旧口径结论：象棋整体功能、内容量与验收尚未达到 80%。用户随后曾将进入下一棋种的阶段线改为“可玩功能达到 80%”，最终又明确作废这一跨棋种启动门槛。**本页仅保留历史质量基线，不限制围棋或其他棋种开始开发。**模拟器设备端及视觉测试继续执行。

以下表格保留旧口径的历史复核证据，不代表新的可玩功能阶段线判断。此前要求同时按功能、内容量与验收判断 80%，并选择暂不分配象棋单独关卡配额；未定量前仍不可宣告内容量达到 80%。当时进度表与象棋有关的 38 个工作项中 34 项标为完成、4 项进行中；34/38 不等于棋种整体完成 89.5%。
