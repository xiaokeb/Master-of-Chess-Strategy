# 中国象棋 AI 先手

对应正式需求 2.2.3：默认玩家先手，可在设置中改为 AI 先手。

## 使用规则

- 设置 → “象棋 AI 先手”，默认关闭。开启后 AI 执红先行，玩家执黑；不改变红先黑后的象棋规则。
- 适用于标准人机、让子、限时、连胜、盲棋和棋力评测的新对局。
- 继续存档保留原执子方。标准人机、让子、限时、盲棋可用“重开”应用最新设置；进行中的连胜和评测系列保持原身份，直到新建系列。
- 残局仍由关卡指定红方挑战；自由摆局的先行方由局面决定、玩家仍执红；本地双人和双 AI 演局不受该设置影响。

## 对局与界面

- `playerSide` 控制玩家权限；当前行棋方不是玩家时由现有 Pikafish 执行。难度参数、合法着约束与历史同步不变。
- 标题明确显示玩家/AI 的红黑身份。玩家执黑时棋盘翻转，棋字保持正向；选子、合法落点、提示、将军光圈和走子反馈使用同一坐标映射。缩放后先逆视图变换，再逆执子视角。
- AI 开局着不能单独悔掉。玩家与 AI 完成一回合后，悔棋回到玩家上一次落子前，保留 AI 的开局着，不重复搜索。
- 引擎胜负、棋钟、认输和棋谱始终按红黑绝对方记录；统计、胜负音效、连胜和评测按玩家身份解释。不通过交换绝对结果来“修正”执黑统计。
- 设置加载完成后才恢复导航，以免冷启动采用未读取的默认偏好；保存失败沿用已有回滚和提示机制。

## 持久化与兼容

| 层次 | 变更 |
| --- | --- |
| Room schema 12 | 设置新增 `aiFirstEnabled`；活动对局与棋谱新增 `playerIndex`（0 红、1 黑） |
| 会话信封 v5 | 从 v4 显式迁移，历史会话默认玩家执红，MOCX 2 字节不变 |
| 备份 v3 | SETTINGS 在更新时间前追加开关；ACTIVE、RECORD 末尾追加玩家索引 |
| 备份 v1/v2 | 继续可读，缺省开关关闭、玩家索引为 0，旧精彩局偏好保留 |
| 单局导出 JSON v2 | 增加 `playerIndex`，保留原绝对结果与引擎状态 SHA-256 |

非法玩家索引、或在不支持切换的模式伪造执黑身份，均在持久化/备份校验边界拒绝。
棋谱标题保留玩家身份，回放沿用原执子视角；收藏不改变不可变的终局载荷。
