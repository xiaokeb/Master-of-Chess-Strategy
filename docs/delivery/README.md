# 交付文档

本目录逐步维护：

- CHANGELOG：已完成节点和行为变化。
- 用户操作手册：正式玩法可用后编制。
- 二次开发手册：模块接口稳定后编制。
- 测试与发布说明：Release 候选版本产生后编制。

交付文档只描述已经实现和验证的能力，不提前宣称计划功能可用。

每个大节点交付前记录：

1. 完成范围与明确未完成范围。
2. 使用的 JDK、SDK、NDK、CMake 和 Python 环境。
3. 单元测试、Lint、APK 构建、原生编译和设备测试的独立状态。
4. Git 提交与远程推送结果。

“仅编译”和“已运行通过”必须分开描述；没有设备时不得把 Android 原生测试写成通过。
