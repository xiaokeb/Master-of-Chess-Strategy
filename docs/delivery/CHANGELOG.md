## 2026-09-25 中国象棋自由摆局 FEN 转换

- 增加与内置 Pikafish 输出一致的六字段象棋 FEN 解析、规范化导出和自由摆局粘贴/复制操作。

- 自由摆局手工放子同步拒绝不可达兵、士、象落点及将帅照面。

## 2026-09-25 中国象棋残局固定落点门禁

- Python 生产审核与 Android 资源解析同步拒绝未过河却位于奇数列的兵卒，以及无法按斜行规则到达的士、象位置。
- 正反例回归覆盖红黑双方；现有 v4 十关不变，无需迁移用户通关记录。

## 2026-09-25 中国象棋自然限着终局优先级

- 修正第 120 个连续未吃子着同时将死对方时误判为和棋的问题；仍有合法着法的自然限着继续判和。
- 增加 Android NDK 原生回归用例，覆盖临界着与序列化恢复后的胜负。

## 2026-09-25 中国象棋残局 v4 可达性门禁

- 项目 Conda 环境新增零依赖离线审核器，输出确定性索引，检查结构、去重、棋子数量和基础可达性；不代替 Native 规则或授权审查。
- 审核发现大师奖励关的红兵位于不可到达的 y=7；移至合法 y=6 后由原生引擎再次穷举确认唯一将军一步杀。
- 内容升级 v4，稳定 ID、已完成进度与奖励保留；旧活动残局按版本重开正确局面。

## 2026-09-25 中国象棋存档终局重算

- MOCX 有效历史恢复后由当前规则重算历史裁定，旧规则结果和可重算 CRC32 的伪造结果均不再覆盖真实局面。
- 无历史与有一步合法历史的伪造“和棋”回归用例先失败后通过；既有长将终局保存与恢复继续通过。
