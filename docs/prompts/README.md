## 使用规则

1. 只在对应场景读取相关模板，不把模板当作独立需求。
2. 同时引用正式需求、当前接口和已经确认的技术约束。
3. 替换全部占位内容；示例包名、版本和类型不得直接复制。
4. 引入开源引擎或数据前核验来源、许可证、版本、体积和移动端限制。
5. 生成的代码、数据和测试均须经过项目构建与可读性检查。
