# 虎羊棋正式人机进程恢复

棋盘有 37 个落点。每个落点现在是一个与画面位置对齐的无障碍节点。可操作时显示点击动作，终局和保存期间保留落点描述并锁定动作。触控仍从同一个棋盘计算落点。

独立 Debug 入口使用 UUID 隔离数据库和专用进程，执行现有模式选择与正式人机页面。测试让玩家执羊，等 AI 完成移羊后终止进程。重启继续同一棋局，随后由玩家认输并再次终止进程。每次重启前后比对棋局身份、版本、动作、执方、阶段、胜方、棋盘和原生存档的 SHA-256。

[复验脚本](../../../tools/android/tiger-goat/test-formal-process-restart.py) 可使用安装了同一 Debug APK 的 Pixel 7 Pro 模拟器。脚本只终止本次启动并核对名称的专用 PID。

## 验收

首次检查在打开 Android 无障碍树时触发 Compose 单节点超过 32 个自定义动作的异常。修复后设备树显示 37 个落点，校正了测试脚本最初误用的 33 点预期。最终使用同一修复 APK，活动和终局均通过真实进程终止恢复。核对 4 张画面及两份无障碍树。行棋中 37 个节点均可操作，终局均禁用。

20 项 JVM 与 2 项模拟器触控和导航回归通过。NDK 30 双 ABI、Debug 主 APK、测试 APK 和 Release 主清单通过，Lint 0 错误、25 警告。Release 清单中没有专用进程测试入口。实体设备和辅助技术语音输出仍待验收。
