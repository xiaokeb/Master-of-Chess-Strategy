# 虎羊棋规则教程

本地棋盘的「规则教程」打开四步课程。前三步使用独立原生棋局练习开局移羊、摆羊与老虎沿线走步。第四步检验可继续连跳或自愿结束的规则。错误答案不会推进，完成后可返回原对局。

进度写入虎羊棋专属的 `tutorial_progress` 行，沿用全量备份的教程进度格式。存盘串行核对已完成步数，重复提交幂等，不能跳过前置步骤。备份恢复后，原页面的保存身份失效。四步完成记录可供正式人机入口检查简单档资格。正式人机页面、更多规则练习和难度梯度另行验收。
