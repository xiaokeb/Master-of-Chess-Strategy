## 独立接口

头文件：`engine-native/src/main/cpp/include/mocs/engine/tiger_goat_ai.hpp`。

`search_action(const TigerGoatGame&, SearchLimits, SearchCancellation)` 返回 `SearchResult`。

| 项目 | 语义 |
| --- | --- |
| `turn_depth` | 实际换手深度，允许 1–16；默认 3，不代表已校准难度 |
| `node_limit` | 最多尝试的子动作数，含各次迭代；0 立即停止 |
| `time_limit` | 单调时钟合作式预算，允许 0–60000 ms；默认 1500 ms；0 立即停止 |
| `SearchCancellation` | 同步高频 `noexcept` 回调与调用方持有的上下文；需线程安全、快速且不得改搜索局面 |
| `action` | 仅返回在私有副本实际执行成功的根动作；未完成首轮时可能只有合法回退动作 |
| `score` | 只有完成整轮根搜索才有值，固定为原局当前方视角；不是胜率或棋力分 |
| `completed_turn_depth` | 已完成的整轮换手深度；未完成为 0 |
| `visited_nodes` | 子动作尝试数，永不超过节点预算；时间/取消检查不计节点 |
| `stop` | 完成目标深度、无合法动作、节点/时间/取消、参数无效或规则拒绝 |

取消结果即使带旧动作也不能据此自动落子。将来上层还必须核验会话身份、局面版本及生命周期。终局返回无动作；达 65535 动作历史上限时，不把规则拒绝伪装为停着、胜负或有效搜索结果。分配失败向调用方传播，原局与撤销历史不变。

## 搜索与预算

迭代加深＋Alpha-Beta，保持规则层稳定动作顺序，不截分支、不随机降级。以原局当前方作固定视角，节点根据真实 `to_move` 决定最大化或最小化；仅当子局面换手时递减深度。因此虎连跳不会错误取负或提前耗尽深度，自愿结束动作会正常换手。

同方连续动作只能是虎连跳：每次继续均移去一羊并记录落点，结束则换手，因此链有限；不额外截断动作数改变规则。搜索仅复制一次原局，子树采用 `apply` 与 RAII `undo`，提前返回、取消和分配异常均撤回私有子动作。

叶评估：胜负为 ±100000；未终局以虎视角计算 `已移去羊数×120 + 虎正交空邻点数×12 - 无正交空邻点的虎数×80 - 有羊邻点的羊数×2`，羊视角取负。该启发式不把“没有普通空邻点”当成规则围困（仍可能有跳吃），真正胜负始终由规则引擎给出。

每个子动作前、递归入口、动作生成后检查停止条件；复制和固定 37 点规则操作之间也检查。被打断的一轮不会覆盖上一轮完整结果，初始回退动作必须已实际执行成功。预算不是硬实时抢占：单次固定规模规则操作、内存分配或调用方取消回调可能在预算耗尽后才返回；移动端耗时与暂停延迟仍需实测。
