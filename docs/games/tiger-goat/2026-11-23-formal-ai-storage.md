# 虎羊正式人机存储与备份

正式人机复用 `active_games` 已有的虎羊活动行。模式为人机，难度为简单，`playerIndex` 以 0 或 1 表示执虎或执羊，`sessionVariantId` 保存正式模式版本和修订号。`engineState` 保存原始 MOCT，载入与存盘均经原生回放核验。Room 表结构和迁移版本沿用现有契约。

正式存储固定一次备份门禁身份。在 Room 事务中比较上次读写的整行，主动拒绝旧 owner 覆盖新记录。完全相同的写入可重试。本地双人与正式人机共用一个活动位，从各自入口的存储层直接写入时会拒绝覆盖其他模式。跨模式替换需要生产页面接入显式确认。

备份容器继续使用 v5。原 `TIGER_GOAT_ACTIVE` 七字段格式 1 仍解码为本地双人。九字段格式 2 在原顺序后追加修订号、人类执方，恢复为正式人机。两种格式均要求实际 JNI 接受 MOCT 后才进入全量备份事务。

Pixel 7 Pro 的独立磁盘数据库通过正式棋局备份、恢复、重开和逐字段核验。另验证过期 owner 及跨模式覆盖被拒绝。旧本地双人与象棋混合备份、损坏棋局拒绝及事务回滚通过回归。共 18 项 JVM、15 项模拟器测试。NDK 30 双 ABI、Debug 主包、测试包和 Release 主清单构建通过，Lint 0 错误、25 警告。[证据清单](../../releases/manifests/v0.1.0-tiger-goat-formal-storage.1.json)
