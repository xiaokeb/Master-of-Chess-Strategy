# 兰州麻将首结事务与 schema 26

迁移 25→26 增加正式创建与终局收据两张表。两表以会话 ID 为主键，收据引用正式创建。迁移从空账本起步，原有表的结构与数据保留。

正式创建在既有数据库 Owner 门禁内核对当前活动局和资格，并在同一 Room 事务中落下经原生引擎校验的初局与创建依据。终局以已保存的棋谱为动作前缀，重放完整历史，由引擎给出赢家和四席金额。收据和终局同时提交。相同请求重试保留首次回执，资格不足、会话已变更、旧局缺创建依据或写入失败时保留原活动局。

## 验证

- Pixel_7_Pro 四项仪器测试通过，覆盖 25→26 迁移、并发首结与重新打开真实磁盘数据库、写入触发器故障后的事务回滚，以及旧活动局和过期请求拒绝。
