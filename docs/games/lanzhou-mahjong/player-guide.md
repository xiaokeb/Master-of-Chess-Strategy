# 兰州麻将使用说明

从首页选择“兰州麻将”，进入学习与对局菜单。初次游玩先学习十课教程，每课答对并保存成功后解锁下一课；复习不重复写入进度。保存失败时点击“重试保存本题”，确认前不会增加掌握课数。

十课全部完成且没有活动局时，菜单提供“创建简单新局”。中等、困难、大师按需求分别需要简单10胜、中等15胜、困难20胜；可信胜场链尚在开发，当前不开放这些难度的新局。历史较高难度存档可继续原局，但不能凭旧存档重开同难度新局。

牌桌中先点选自己的手牌，再选择当前可用动作；其他三席自动行动。只有符合当前规则的动作才会出现。提示、悔棋与报听操作以牌桌实际可用按钮为准；简单局提示和悔棋不限次数。新局炸胡采用项目桌规：向其余三家各赔24倍底分，合计72倍；旧v1存档仍沿用每家8倍。

点击“返回”会先确认待保存的牌局，再退出。保存未成功时保留当前牌局，可重试；不要把菜单读取失败当成存档已经消失。已有活动局时，菜单明确显示原难度，并提供“继续”入口；不会用新难度选择静默覆盖原局。重开也会重新检查教程和难度资格，检查失败时保留当前局。

在设置中可以导出或恢复完整本地备份，包含独立十课进度及当前对局。恢复会替换本地数据；恢复后返回并重新进入相应页面。文件不加密，含完整私有牌墙，应妥善保存，不作为公开牌谱分享。

本节点仍属开发中的源码预发布：可信胜场、成长与棋谱、完整音效及后续内容尚未交付，AI强度与实体设备尚未验收。教程问答完成不能代表棋力评定。
