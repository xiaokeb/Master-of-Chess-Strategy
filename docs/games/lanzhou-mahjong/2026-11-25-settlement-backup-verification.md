# 兰州麻将首结账本备份验收

备份容器 v5 新增 `LANZHOU_MAHJONG_SETTLEMENT`，每条记录包含一个正式创建凭据和至多一份首结收据。导入前校验会话身份和创建初态，重放终局并核对赢家、付款席和四席金额。活动局与账本身份相同时，活动终局必须与收据棋谱完全一致。没有正式创建凭据的旧活动局可照常恢复，其结果不计入可信胜场。

导出会检查两张账本表的归属，并验证同样的棋谱证据。恢复在既有兰州麻将存储门禁和整个容器的替换事务中，先清收据、再清创建凭据，随后按创建和收据的顺序写入。旧备份省略账本时，完整恢复清空现有账本。

Pixel_7_Pro 的 10 项仪器测试通过，包括两项新增账本测试、四项首结事务回归和四项旧活动局备份回归。测试验证正式终局、废弃开局和四席金额跨导出、恢复及数据库重开的一致性，也验证改写付款、缺少活动终局收据的备份被拒绝并保留原数据。

NDK 30 编译 x86_64 和 arm64-v8a，Debug 与仪器 APK 构建成功，Android Lint 为 0 错误、25 警告。设备证据保存在 `.build/lz-settlement-backup1/device-f3b439b37ac1451485423ca7aa98eb1b/instrumentation.log`。正式桌的创建、存盘与可信胜场解锁仍待切换到新账本。[基线和证据散列](../../releases/manifests/v0.1.0-lanzhou-mahjong-settlement-backup.1.json)
