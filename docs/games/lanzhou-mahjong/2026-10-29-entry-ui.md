# 兰州麻将正式入口页面切片

本切片仅新增菜单ViewModel、纯Compose页面及对应测试。接收Root的`LanzhouMahjongEntryRepository`，不修改已发布十课、Host、数据层、导航或公共文件；Root负责正式路由注册与Host创建/重开的实时授权。菜单只调用`loadFacts()`，不调用`authorizeNew()`，按钮不是唯一准入守卫。

## 接口与页面

`LanzhouMahjongEntryViewModel(repository, worker = Dispatchers.IO)`暴露`state`、`reload()`、`resume()`和`LocalDataWriterRetirement`。状态为`LanzhouMahjongEntryState(loading, facts, error, retired)`，内部`lastFailure`保留原始异常。`resume()`首个生命周期恢复复用构造读取，之后每次返回请求新读取；重叠刷新合并为下一次读取，不发布已过时的前一次结果。Root应在菜单`ON_RESUME`调用`resume()`，按导航条目及epoch持有VM，并注册同DB写者屏障。

`LanzhouMahjongEntryScreen(state, onLearning, onResume, onNewEasy, onBack, onRefresh)`是纯页面。实际学习快照缺失显示0/10，存在则显示真实课数。已有活动局时显示并提供“继续原难度对局”，不提供替换新局；即使教程不完整，也可明确续接合法存档。无活动局且十课全部完成才提供“创建简单新局”，否则提示完成教程。始终提供学习/复习入口。

页面列出中等需简单10胜、困难需中等15胜、大师需困难20胜，同时明确“可信胜场来源尚未接入”，不虚构0胜统计、不提供高难度创建按钮。读取失败只提供重新读取与返回；加载和退役期间隐藏旧资格。纵向布局允许窄屏及大字号滚动。

稳定测试标签均以`lanzhou_mahjong_entry_`开头：`back`、`progress`、`learning`、`resume`、`new_easy`、`trusted_wins_pending`、`refresh`、`error`；根标签为`lanzhou_mahjong_entry`。

## 生命周期

VM固定捕获一次ownerEpoch，主动监听epoch变化。入场与退役同步互斥；独立worker scope保有已接受读取，UI线程不执行数据库操作。退役同步拒绝后续刷新并清除可用事实，等待当前读取结束后完成同一retirementCompletion；onCleared走相同路径。读取异常仅映射固定中文提示，不展示SQL、Native、路径或原异常文本。读取失败不写记录，不将失败当成零课事实。
