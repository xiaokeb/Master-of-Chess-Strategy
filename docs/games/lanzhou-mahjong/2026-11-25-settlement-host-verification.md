# 兰州麻将正式桌首结验收

正式桌开局和重开先把初始棋谱及正式创建凭据一次写入 Room，再推进 AI。开局写入失败时保留同一待保存请求，重试仍使用原时间和初局。写入事务重新校验教程与当前活动局。

正式桌普通存盘核对已确认的活动局。终局由原生引擎重放，四席收据与终局活动局共同提交。旧活动局仍能保存及续局，其终局没有可信首结来源。更高难度所需的可信胜场解锁尚未开启。

36 项宿主与入口 JVM 测试通过。Pixel_7_Pro 的 9 项正式宿主与入口仪器测试通过，覆盖开局写入故障后的回滚与重试、真实完整桌局保存四席金额、坏存档保护、替换退役及续局。NDK 30 双 ABI、Debug 和仪器 APK 构建成功，Android Lint 为 0 错误、25 警告。

视觉复核覆盖标准字号横屏牌桌，以及标准和 150% 字号的竖屏牌桌。150% 字号的错误与返回页采到横屏，牌桌测试页面在同次运行中回到竖屏，150% 横屏牌桌仍待专项验收。截图和日志存放于同一阶段产物目录。
