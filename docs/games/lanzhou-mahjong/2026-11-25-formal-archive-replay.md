# 兰州麻将正式棋谱回放

从兰州麻将入口选择「查看正式棋谱」。记录按收据时间倒序分页，每页最多 20 条。打开记录后可以从初始牌局逐步前进、后退或跳到终局，查看各席弃牌、副露、净分和结果。

列表由正式创建与首结收据连接得到。打开步骤时，先核对正式创建摘要并重放完整终局，再用原生规则引擎恢复指定动作前缀。回放沿用当时本机座位，只展示该席手牌、对手公开信息和所有席位的结算数据。失败时保留原资料；备份替换后需要重新打开棋谱。

此节点为只读浏览。收藏、删除、共享棋谱筛选和跨棋种个人中心另行接入。正式首结仍是统计与难度资格的来源。

Pixel_7_Pro 通过三项仪器用例，验证真实完整胡牌棋谱的中间与终局状态、炸胡四席金额、备份恢复后的新旧读取者、坏收据拒绝，以及页面前进、后退和返回。另以 150% 字号执行横屏回放复验，检查实际 3120×1440 画面。NDK 30 双 ABI、Debug APK 与仪器 APK 构建通过，Android Lint 为 0 错误、25 警告。
