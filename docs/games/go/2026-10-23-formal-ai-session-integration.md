## 顺序与边界

1. 专属 Session 增加显式“正式全新标准局创建”事务端口，只有正式工厂创建的零事件真人标准新局调用。正常恢复／旧局保存、指定开局、让子和自动演局不得顺带创建来源；失败须按现有丢失确认写入协议重读，不能误报成功。
2. 正式真人终局双方确认后，先持久固定结果，再提交真实完成 sink；固定后不可悔棋。失败显示完成保存待重试，不开始新局、不解封已固定结果、不重复成长。恢复终局／关闭页面／备份退休须等待同一事务；训练默认行为与旧测试保持兼容。
3. 新增真实 Native＋UUID磁盘Room Session专项：创建与恢复不升级旧局、首次完成即写一次、失败／取消／关页后重进重试、固定结果不能悔棋、实际收藏／统计与备份epoch一致。搜索使用明确脚本只验业务，不宣称 NN 棋力。
4. 通过后接正式 VM／Route、教程与难度资格刷新、可信来源展示和现有合法模型 loader；模型失败不丢已有对局，后台／退出取消并等待资源释放。公共导航、字符串、构建与Git仍仅Root串行修改。
5. 受影响 JVM、双 ABI、Lint、实际生产入口／模型失败恢复及100%／150%可玩与视觉检查通过，再按独立节点发布。真实 NN 搜索、四档强度、性能／音效与实体设备分别记录，未验收的不能用数据接口测试代替。
