# 正式 AI 设置入口：一致读取与原子新建

本切片是正式设置／恢复页的数据端口，不是页面可玩或设备验收记录。需求以 [入口计划](2026-10-23-production-ai-entry-plan.md) 为准；不修改规则、schema18、GAI6、备份或其他棋种。

## 接口与行为

`GoAiEntryRepository.load()` 在同一 epoch 门禁和 Room 事务中读取活动局、真实规则阶段、终局固定／投影状态与十课／可信胜场资格。`GoAiEntrySnapshot.active` 为已有不可变 `GoAiSavedMatch`，其所有字节访问都复制；无活动局时阶段为 null。读取不补发正式来源，旧文件迁移若遇资格读取失败，活动行和永久迁移封口一起回滚。

`create(config, expectedActive, abandonOngoing=false)` 使用真实 Native 初态和全新规范 UUID，成功持久保存后才返回。`expectedActive=null` 明确表示仍预期无活动局；非 null 比较整个规范 GAI，不只 ID，同局走了一步也必须重新确认。保存确认丢失时，调用方重新读取活动局，不自动重试创建第二盘。

- 进行中／数子局只有显式放弃后才可替换。清活动行、新初态及正式来源在同一事务，晚失败或取消均保留原局；不删除归档、原棋谱或旧正式创建事实。
- 任何已终结旧局必须先固定并入谱，即使传入放弃标记也不能绕过。未知旧来源可保存普通棋谱，但不会补来源或成长。
- 标准真人新局写正式来源；自动与让子新局只写普通训练快照。三者均严格检查十课与 10／15／20 可信胜场，不因训练模式绕过难度门禁。
- 捕获的旧 epoch 不允许读取或创建。新增内部 creator 入口只供外层已经持门禁和事务的设置仓储调用，避免嵌套非重入门禁；旧 `create(match)` 保留自行持锁／事务且不能放弃旧局的原行为。

## 验证边界

最终私有 Kotlin 编译使用已验 gfs3 类路径及 friend 元数据，单 CPU／512 MiB，没有 Gradle 或新依赖。`GoAiEntryRepositoryInstrumentedTest` 的 **11 个新方法**与既有 `GoRankedGrowthInstrumentedTest` 整类一起编译；最终日志、参数、六份直接输入 SHA 与收据位于 `.build/go-ai-entry-store-20261024/r5/`。较早 r1 仅有一条可省略安全调用提醒，r2 后消除；之后补真实 Job 取消、有限等待与 UUID 边界，最终按新源重编，不沿用旧编译身份。

测试源码覆盖：一致读取／标准来源；同 ID 全历史变化拒绝；行棋／数子显式放弃；晚失败与取消异常回滚；真正取消已进入事务的 Job；首次保存迁移封口回滚；旧终局必须固定＋投影；自动／让子无来源且不绕过资格；旧文件未知来源保留；epoch；读取晚失败回滚迁移。不是新 NN 对局、强度、音效、UI 或真人设备证据。

本专属切片未运行 NDK、ADB、Gradle 或 Git，**仪器方法只编译，尚未上机执行**。生产 Bundle／Storage 工厂、设置 VM、Route、导航、writer 清退与最终模拟器／视觉由统筹串行接线和验收；未把本切片当作已发布功能。
