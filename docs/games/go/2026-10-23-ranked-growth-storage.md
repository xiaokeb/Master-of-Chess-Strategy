# 围棋正式新局与首次成长数据事务

## 范围

接续已发布的完成棋谱节点。Root 串行拥有 Room、公共备份、统计工厂及 Go 数据 bundle；独立代理仅负责纯策略和专属设备测试。无账号、联网排行或反作弊需求，不引入密钥和签名体系。

## 已写源码，待验证

- schema 18 仅新增 `go_ranked_starts`、`go_ranked_settlements` 空表；旧局和旧成绩不自动提权。
- `RoomGoRankedMatchCreator.create` 是显式正式创建入口；必须规范 UUID、标准零事件真人局、完成十课并满足 10/15/20 可信胜场门槛。已有活动局不能补来源，未固定/未保存的旧终局不能被覆盖。初始 GAI、创建事实与旧源处理标记同事务保存，失败/取消全部回滚。
- 完成 sink 配对正式创建与首次不可变 Native 终局，在同一事务保存棋谱、投影、成长结果与结算关联；重复请求不重发，收藏与首次时间保留。自动参与、导入、让子、指定开局、终局延续及本机时钟回拨保留普通棋谱而不增长。
- 显式原始归档回填只生成普通棋谱，不结算成长。无正式来源的旧 Go outcome 保留且可备份，但数据库版统计工厂不将其计入成长；Go 的直接 `record` 被拒绝。
- 完整生产备份 bundle 新增两种独立元数据记录，仍由核心 OUTCOME 独占成长 payload。恢复前校验正式初始来源、首次归档、棋谱投影和核心 outcome 一致；恢复事务先删除关联子表，最终检查 deferred FK，旧备份清除新表但不补来源。
