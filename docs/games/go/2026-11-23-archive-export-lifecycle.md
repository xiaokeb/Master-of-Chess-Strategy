# 围棋归档 SGF 导出恢复

在已归档棋谱的回放页启动系统「另存为」后，页面重建可能早于文件选择结果返回。导出请求现由当前导航条目的 ViewModel 保存，持有发起时的存储代次和待写入的 SGF。记录 ID 用于隔离同一条目内不同棋谱。SGF 仅保存在内存，完整进程终止后应重新发起导出。

选择文件后仍在原存储代次内写入。取消选择清除请求。若本地备份恢复已替换数据，旧请求不能写入文件。归档、回放位置及战绩保持原状。

新增设备用例调用真实系统文件选择器并暂存其返回值，卸载并重建回放页面后再投递，最后逐事件核验导出的 SGF。已有取消、完整主线及备份换代拒写用例继续作为回归。该用例覆盖页面组合重建。

10 项 JVM 与 4 次 Pixel 7 Pro 模拟器测试通过。已核对普通和 150% 字号下的系统文件选择器、正常归档导出和旧存储拒写画面。组合重建用例未杀死进程，也未重新创建整个 Activity。NDK 30 双 ABI、Debug 主 APK、测试 APK 和 Release 主清单通过，Lint 0 错误、25 警告。实体设备待验收。
