# 围棋残局首通奖励验收

每道残局首次通过计 1 星。简单、中等、困难分别计 10、20、40 分。奖励由已提交的关卡 ID 集合计算，已有进度和恢复后的备份采用同一规则。重解、重试保存或重新导入相同进度均按同一关卡 ID 计一次。奖励进入首页和个人中心的本地成长，围棋人机胜场及难度资格继续由正式对局结果计算。

沿用 Room 的围棋进度行和原 `GEP1` 格式。保存成功前只显示待保存状态。首次提交后显示累计奖励并刷新个人中心。原七关的完成记录对应 7 星、120 分，当前九关全通对应 9 星、200 分。
