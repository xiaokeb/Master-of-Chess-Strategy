# 围棋一气双提与一点接三组

在既有 14 题后加入两道项目自编题。九路「一气双提」要求找出两颗独立白子共同的最后一口气。十三路「一点接三组」要求一手将三组黑棋相连。练习页标记目标棋组，不标出答案。

原生验证遍历所有合法落点，确认两题分别只有零基坐标 (4,4) 和 (6,6) 达成目标。主线首通各加一星、40 分，旧 14 题累计 460 分不变，全目录达到 16 星、540 分。

55 项 JVM、4 项原生规则用例与双字号共 2 项生产导航用例通过。已核对 8 张题面与通关画面，去掉初次进入时重复显示的题面。双 ABI、Debug 包、测试包及 Release 主清单通过，Lint 为 0 错误、25 警告。实体设备及完整题库规模待验收。[发布清单](../../releases/manifests/v0.1.0-go-tactical-groups.1.json)
