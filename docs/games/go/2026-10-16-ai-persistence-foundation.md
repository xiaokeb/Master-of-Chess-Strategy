# 围棋 AI 持久化前置与写入确认

更新：2026-10-17。属于正式 AI 数据接入的前置增量，不代表 Room、完整备份、成长或生产 AI 入口已经完成。冻结的本地数据候选 `rgl1` 不含本次改动，不能沿用其身份或旧 APK 验收本次源码。

## 本次实现

- `GoAiCheckpointAdmission` 先校验完整 GAI1，再用独立规则引擎恢复当前局与指定开局；核对棋盘、让子、贴子、完整事件前缀、双确认终局、胜负与分数。返回拥有独立字节的规范快照、实际阶段和事件数，不搜索、不写存储、不授予奖励。
- AI 棋谱 ID 使用独立 SHA-256 域及稳定 matchId，不与本地双人会话 ID 混用。合法历史不等于可信参赛身份，不能凭 CRC 或 Native 恢复发放标准胜场。
- 未固定结果的终局悔棋生成新 matchId；普通悔棋保持 ID，已固定结果仍禁止悔棋。开局、人工方、自动参与来源、自动续局策略及辅助已用次数均保留，新身份仅在持久化被确认后发布。将来 Room 必须保留父终局及子局的延续来源，不能因换 ID 重获标准资格。
- 会话全部十处保存改用统一写入确认。正常成功不额外读取；保存抛错时精确重读完整 GAI1：等于新快照则认定已提交，等于上次持久化快照才按旧状态处理。读失败或出现第三种快照则停用旧页面、取消后续任务，提示返回重进；不继续用过期状态覆盖磁盘。

文件写入成功后仍可能在读回确认时抛错，因此旧文档中“任何保存失败均保持磁盘旧局”不是当前可用保证。这里解决的是丢失写入确认，不能宣称任意文件系统故障均可回滚；取消异常仍按取消传播。

## 接续：只读旧源与事务核心

`GoAiLegacyDiskSource` 只读 `.bak` 优先、其次主文件；不恢复/重命名/删除 AtomicFile，不从 `.new` 提升未提交状态。读取最多完整 GAI 容量＋1 字节用于拒绝超限（包含两份各百万字节历史及头/ID）；坏备份不能回退到有效主文件掩盖错误。v1–v6 原封保留，仍须后续真实 Native 准入。

`GoAiCheckpointRepository` 与专属事务端口已实现，但尚无 Room 实现或生产注册。活动规范快照、完整终局 GAI 来源、首次完成时间与永久旧源标记按端口要求同事务；即使第一次调用直接 save，也先准入旧源终局，后续写失败须全部回滚。终局反复固定结果/结束续局不覆盖首次归档；同 ID 不能改终局历史、回退来源/辅助标记或重新变成进行中，clear 仅清活动槽并永久封口，不删父终局。

终局后非初态新 ID 保留被替换父谱的关联，明确只是保守替换上下文，不宣称已证明父子历史前缀。当前三个来源均无排名资格；遗留来源不会因普通保存升级。终局来源保留完整 GAI，不受共享记录列表尚有的 10000 步投影上限截断；它还没有写入共享 GameRecord 或完成账本，不能算“正式棋谱列表和成长已接通”。Room、投影、备份和 epoch 清退仍须后续一起集成。

## 后续实施顺序与边界

1. 新建专属 AI 活动快照、完成来源及事务端口；实现 Room 仓储，再由 Root 串行接 schema16。现有 schema15、GAI1 v6 与 v1–6 读取兼容不在本增量修改。
2. 旧 AI 文件按只读、有限大小的已提交文件规则迁移，并有独立永久封口。有效全量恢复即使不含 Go 也需封口，防止旧文件复活；坏源不能部分落库。不能把会修改文件的 `AtomicFile.openRead()` 当成只读迁移器。
3. 活动快照、真实终局棋谱、来源及符合条件的完成账本在同一事务；幂等保存保留原收藏/时间，终局父谱不可回退成活动局。遗留、导入、让子、自动参与与延续训练不能凭新 ID 自动获得标准排名资格；GAI1 v6 没有“纯自动”真实性证明，不臆造该标签。
4. 扩展现有 Go 棋谱单一所有者与恢复配对校验，再加 AI 活动 kind；不让两个适配器互相清掉对方记录。保持旧备份兼容及完整替换事务，在真正覆盖 AI 前保留 `GoAiDiskBackupGuard` 拒绝保护。
5. 生产接线使用同一 epoch 门闩；备份/恢复须等待搜索、会话和运行时真实清退。现有 AI ViewModel 的独立 cleanup scope 不能仅靠 viewModelScope 已取消判断完成。完成此屏障后再开放导航，不先绕过锁定条件。
6. 共享窗口可用后执行必要 KSP/迁移、定向 JVM、双 ABI/Lint、真实 Native/Room/备份恢复、正常及 150% 视觉与杀进程验收；满足节点门禁才显式暂存、提交推送、tag 和 Release。

长局 Native 事件上限与共享 GameRecord 步数上限不同，归档必须给出明确处理，不能以静默截断历史或预先拒绝所有合法活动长局掩盖。当前没有新增标准成长账本、schema16、AI 备份适配器或生产 AI 路由，也没有新发布。
