# 围棋正式新局与成长候选策略

## 范围与依据

依据 `docs/requirements/PRD.md` 的普通人机、分级辅助和本地成长需求，以及已发布的 GAI 准入、原始终局归档和棋谱投影边界。本切片只新增纯策略，不修改 Room、备份、Session、导航或奖励实现。

来源事实仅代表**本机正式新局创建流程**；不是网络排行、真人证明、反作弊或防篡改。CRC、合法历史与规范 UUID 都不证明是谁执行了走步。不得从导入、旧 GAI 或既有普通棋谱倒推并补发此来源。

## API 与不变量

- `GoRankedStart(recordId, canonicalInitialGai, createdAtEpochMillis, version=1)` 保存不可变创建事实；构造与 `copyBytes()` 均防御复制。时间非负、记录 ID 为小写 64 位 SHA，暂只接受版本 1。
- `admitGoRankedStart(match, time, engineFactory)` 重新执行引擎准入，绑定规范 GAI 与 AI 域记录 ID。matchId 必须是 `UUID.fromString(id).toString()==id` 的规范 UUID；初始必须为 PLAYING、ONGOING、零事件、无让子、真人执黑或白、无指定开局、从未自动参与、未消耗悔棋/提示、未保留终局、未启用自动系列。
- `qualifiedGoOutcome(start, firstRawArchive, engineFactory)` 自行重验初始和终局引擎历史及规范 GAI；调用方不能传入可伪造的已准入元数据绕过检查。ID/规范字节/历史损坏冲突抛出异常。
- 合法但不合成长要求的归档返回 `null`：旧来源、终局延续、混合/自动参与、指定开局、让子、改规格/真人执色/难度、自动系列、尚未双方确认终局。普通无损棋谱仍可保存。
- 完成早于创建可能是本机时钟回拨，返回 `null` 而非认定数据损坏；不要求用户调时间。相等和 `Long.MAX_VALUE` 边界可通过，无差值溢出。
- 终局允许本难度合法额度内的悔棋与提示；GAI 自身负责额度约束。不将合法分级辅助误判为自动参与。
- 结果沿用 AI 域 SHA 记录 ID、GO/HUMAN_VS_AI、四级显式难度映射、真人执色和原始归档首次完成时间。返回值是 `MatchOutcome?`，本函数不写数据库、不结算奖励。

## 生产集成义务

创建事实必须与全新活动 GAI 原子保存，不能给已有活动局补来源。完成候选必须配对**首次不可变原始归档**，不能用后续时间或再次生成的终局替换首次事实。调用方仍须在同一事务校验来源、棋谱、首次原始归档和幂等成长结算，并处理备份来源配对；纯策略不承诺这些尚未接入的事务已完成。

## 本切片验证

私有命令：`./.build/go-ranked-policy/check.ps1 -RunName private-r2`。

- Kotlin 编译及 JUnit **13 个测试方法通过**，单 CPU、512 MiB、断言开启，复用已发布 gca4 类路径，输入 SHA 前后核对。
- 覆盖 9/13/19 路 × 真人黑白 × 四难度（48 组合），合法辅助、非法创建、规范 UUID、防御复制、旧来源/延续、非标准完成、零/极大/回拨时间、身份/字节/规则冲突、引擎拒绝与终局规范替换、胜负和和棋、已保留终局。
- 测试使用可释放的包络形状规则替身；**不是 Native 合法棋史、棋力、Room、设备或界面验收证据**。本切片未执行 Gradle、NDK、ADB、公共文件编辑或 Git 发布。
- `private-r1` 为首次 11 方法通过的保留证据；`private-r2` 增补终局规范替换及结果映射后为最终 13 方法，不合并计作 24 个独立测试。
