# 围棋人机与自动演局主时限

人机、自动演局和从定式学习发起的新局读取全局时长。时限开启后双方各有一份主时限。落子换手、超时和双方余额随同一个对局快照写入 Room。GAI1 v7 增加余额、当前行棋方和回合起点，旧无时限记录继续按 v6 保存。死子协商暂停主时限，恢复行棋时从规则确定的一方继续。重开及自动续局重新分配双方时限。

本节点沿用本地双人的计时口径。暂停 AI 只暂停搜索和自动走子，主时限继续消耗。AI 搜索预算受本方余额约束。提交时重新校验到期条件，截止时刻返回的走子不会抢在超时前写入。

149 项 JVM、双 ABI Debug APK、仪器 APK 和 Release Manifest 通过，Lint 0 错误、25 条警告。Pixel_7_Pro 用生产导航在 100% 和 150% 字号开启全局时限，分别验证人机和双 AI 超时、Room 唯一归档及重新打开，到期由隔离存档预置。核看四张横屏截图，150% 时自动续局设置可滚动访问。独立设备用例通过完整围棋备份往返，并核对时钟、超时棋谱和再导出字节。

11 月 15 日，Pixel_7_Pro 新增人机和双 AI 的真实进程恢复验证。计时中终止隔离进程，设备时钟在进程缺席期间越过截止时间。重新打开后均为黑方超时、白方获胜，白方时间保留且 Room 只产生一条归档。再次终止并重启后检查点散列及归档数一致。人机进程号依次为 3507、3923、4039，双 AI 为 4219、4573、4684。Debug 和仪器 APK、Release Manifest 构建及 Lint 通过。[复现脚本](../../../tools/android/go/test-clock-process-restart.ps1)

复现时安装同源 Debug 与仪器 APK，再运行复现脚本，传入 `-Adb`、`-Device` 和新的 `-OutputDirectory`。脚本使用独立数据库，仅终止专用测试进程。

Pixel 7 Pro 的熄屏测试从黑方剩余 30 秒、白方 5 分钟的隔离存档继续九路双 AI 对局。实际熄屏后仍有新着法保存，随后黑方超时、白方获胜。结算发生在屏幕仍关闭时，后台通知和唤醒锁随即释放。重新打开同一局后只有一条归档。100% 与 150% 字号各通过一次，共核看四张横屏截图。150% 字号使用操作区滚动查看计时与结算状态。[熄屏验收记录](../../releases/manifests/v0.1.0-go-clock-background.1.json)
