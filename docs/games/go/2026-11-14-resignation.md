# 围棋认输与存档兼容

认输是独立终局事件。黑白任一方确认认输后，对方获胜，棋盘保持认输时的状态。认输局没有正式数子结果。双方同意的死子集合仍是数子终局的必要条件。[中国围棋协会规则](https://wqwh.weiqi.org.cn/rules/)

含认输事件的记录写 MOCG v4，其余记录保留现有字节格式。棋谱回放显示认输方，SGF 导出保留可交换的行棋主线。本地双人可选择认输方，人机模式由真人执色认输，双 AI 继续沿用落子与虚着路径。

原生规则专项通过黑白认输、保持棋盘、撤销、旧存档和损坏历史拒绝。82 项 JVM 涵盖共享记录、历史解码、会话、归档投影、棋谱和备份适配器。Android NDK 双 ABI、Debug APK、仪器 APK 和 Release Manifest 通过。Lint 0 错误、25 条警告。

Pixel_7_Pro 的生产页面专项覆盖取消确认、确认认输、Room 单次归档、对局重进及 Native 重放历史。100% 与 150% 字号各通过两项，已检查四张横屏截图，150% 时使用滚动访问返回和底部操作。测试后恢复原字号。

后续设备专项验证完整围棋备份同时包含本地双人和人机的认输记录。导出、替换恢复与再导出字节一致，二者的正式结果、人机收藏和回放终局一致。真实杀进程使用隔离数据库和 Debug 专用进程。进程 29785 与重启后的 29875 返回同一对局 ID、黑方认输、白方获胜、3 个事件、1 条归档及相同检查点 SHA-256。正式棋钟待开发。
