# 围棋连胜挑战

在人机设置选择连胜挑战，可选棋盘尺寸和已解锁的起始难度。玩家执黑，不让子，不计时。沿用项目连胜规则，三胜升档、两负降档，难度上下限为简单和大师。失利或和棋中断当前连胜，保留本系列最佳纪录。

GAI1 v10 保存开局时的系列计数。终局统计和下一局难度从原生赛果计算，恢复终局时可重新计算同一结果。玩家确认后才创建下一局，先固定本局并保存专项棋谱。对局中不能重开、切换为自动演局或导入指定开局。训练升档不解锁标准人机难度，也不增加标准胜场。

v10 头部仍在既有的存档大小预算内，v1–v9 的读写行为保持。Room 校验同一局内的系列计数不变，带进度的下一局须匹配原生已结算上局。专项棋谱沿用既有围棋记录和备份路径。

177 项定向 JVM 用例通过，覆盖升降档、终局恢复、错误封装和成长隔离。Pixel 7 Pro 模拟器在 100% 与 150% 字号各走通一次正式开局、认输、保存专项棋谱、开始下一局和退出续局。已核看六张设置、终局和续局画面，两档字号均可通过滚动操作下方控件。

NDK 30 的 x86_64 和 arm64-v8a 构建、Debug 应用及仪器包、Release 主清单检查均通过。Lint 为 0 错误、25 警告。[首版验收清单](../../releases/manifests/v0.1.0-go-streak-challenge.1.json)
