# 围棋五局定级

人机设置增加棋力定级。玩家完成围棋教程后，可选择棋盘尺寸并进入五局专项定级。首局中等，玩家执黑。胜局升一档、负局降一档、和局保持，难度最低简单、最高大师。专项从 1200 分开始，根据实际对手档位增减，范围为 400–2400。规则沿用项目已有的五局定级策略。

评测期间禁用提示、悔棋、自动接管、指定开局和局中重开。每局终局生成定级棋谱，第五局显示最终评分、胜和负局数和完成状态。定级评分不写入普通成长与胜场，不解锁普通难度。

GAI1 v11 保存该局开始时的评分与赛果计数，结束界面从原生终局重新计算。只有已结算的上局才能生成带有进度的下一局，进度、难度和棋盘尺寸都在持久化时核对。续局读取同一活动记录，第五局完成后无法开始第六局。

180 项定向 JVM 用例通过。Pixel 7 Pro 模拟器以 100% 和 150% 字号各走完一次五局认输路径，确认评分更新、专项归档、继续和禁止第六局。已核看六张画面。独立 QA 进程在第三局进行中与第五局已结算时分别强制终止并重开，实测新 PID 下评分、棋谱数量和检查点散列一致。

NDK 30 双 ABI、Debug 应用和仪器包、Release 主清单通过，Lint 为 0 错误、25 警告。两档字号设备路径使用认输，胜和分支由定向 JVM 用例验证。正常长局与实体设备待专项验收。此为项目内定级，围棋引擎独立强度继续单独验收。[发布清单](../../releases/manifests/v0.1.0-go-assessment.1.json)
