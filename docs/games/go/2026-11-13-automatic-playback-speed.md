# 围棋自动演局倍速与对局音效

围棋正式自动演局支持 0.5x–4x。调整滑块时即时更新演局节奏，完成滑动后保存为本机围棋偏好。普通新局、指定开局、自动续局以及关闭页面后重新打开均沿用该偏好。没有有效偏好时使用 1x。重新打开自动局后仍须手动继续。

倍速控制相邻着法之间的等待时间。更改倍速会重新安排待启动的一着，已进入搜索的着法按原预算完成。偏好存放在 `go-auto-playback-v1`，独立于棋局存档、应用内手动备份和棋谱。导入备份后的倍速取本机偏好。

正式人机和自动演局接入全局音效开关。落子、提子和经双方确认的终局在存档确认后发声。人机胜负声以玩家执色为准，双 AI 有胜方时播放胜局提示。虚着、悔棋、恢复历史和未保存成功的操作保持安静。离开前台停播，离开页面释放播放器。使用项目已有的五个 WAV 和 SoundPool 播放器。
