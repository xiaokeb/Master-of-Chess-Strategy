# 围棋每步限时

围棋人机新局设置增加每步 30、60、120 秒选项。玩家选择后，换手时为下一位行棋方重新计时。数子时停表，恢复行棋后开始新一步。同一行棋方的操作保留截止时间，允许悔棋的难度仍使用原有次数。到期时优先提交超时结果。

每步限时属于专项训练。对局仍可保存、续局和归档。普通人机的胜场与难度解锁继续使用已有正式来源记录。原双方主时限由全局设置提供，每步限时使用各局创建时所选规格。

GAI1 v9 保存每步时钟和盲棋标记。已有 v1 至 v8 继续读取，双方主时限及盲棋沿用相应版本。Room 使用既有封装列。重新进入对局时按原保存截止时间计算，重开时重新计时。

172 项定向 JVM 用例通过，覆盖到期优先、同方保留余额、双虚停表、换手续时、恢复和旧格式。存档校验只允许新行棋方恢复完整步时，普通主时限仍逐步扣减。Pixel 7 Pro 两档字号各执行一次生产入口用例，覆盖真实 AI 应答、换手续时、原截止时间续局、归档与普通成长隔离。四张画面核对了设置与对局。NDK 30 双 ABI、主包、仪器包、Release 主清单通过，Lint 0 错误、25 警告。每步限时的真实杀进程和后台到期尚待专项验证。
