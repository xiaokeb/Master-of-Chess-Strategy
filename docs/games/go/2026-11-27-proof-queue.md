# 围棋带证据的终局复核清单

`review-strength-groups.py` 新增 `proof-queue`。输入现有工作表及一个或多个 `--receipt 路径 SHA256`，校验批次回执、对应原始棋谱、棋块身份和原生日志。同一棋块的多个成功结果只计一次，未覆盖对手应手的棋块仍保留为缺口。

清单按每局尚缺证据的数量排序，同时保留已有个别提子证据的锚点。工作表中的正式裁定及已有 `export` 流程沿用原样。个别证据和整局结算分别保留。

用项目 Conda 环境核验两批原生回执后，121 局待裁定中找到 12 份尚可复用的棋块证据。第 94 槽归并来自两批的两块证据，重复传入同一批回执结果一致。修改汇总散列、修改原生日志和置换棋谱散列三项均被拒绝。19 局正式裁定表与本轮前逐字节一致。

清单位于 `.build/go-proof-queue1/queue.tsv`，SHA-256 为 `c76b350ac3e0006f8353fa0659f0e3bc37032257713ab82ef02ba96d13764bb8`。
