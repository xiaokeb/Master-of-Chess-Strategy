# 围棋两气棋块终局复核

离线复核器新增 `--enclose-in-two 首着 x,y [x,y ...]`。首着须占据至少一个目标两气棋块的气点，且目标棋子仍留在盘上。逐一枚举对方合法首应，验证存在一次后续落子可清空原棋块位置并保持区域控制，再逐一枚举后续合法应手并重放。与指定棋块无关的首着保留未知。

第 11 槽的两气白棋可由黑在 `3,8` 或 `5,8` 先收气。两条路线各覆盖 14 个合法首应和 221 个后续应手。黑在 `3,4` 直接提另一块白棋，覆盖 16 个首应。两种实际提子次序均可重放并得到相同盘面。

按冻结原棋谱正式数子，黑白面积字段从 166:158 变为 188:136，结果由白胜改为黑胜。项目 Conda 环境核对累计裁定表，现有 18 局正式复算，余 122 局、988 个待审棋块。

Pixel 7 Pro 复算通过，第 55 槽两次提子与第 117 槽提子后守住区域的回执均逐字节一致。NDK 30 编译了 x86_64 和 arm64-v8a，小米真机未连接。回执及裁定表位于 `.build/go-enclose-in-two1/`。

2026-11-28 在 Xiaomi 25042PN24C（Android API 37，arm64-v8a）补验第 11 槽。黑方 `3,8` 收气的应手回执、正式数子结果和复算棋谱散列与 Pixel 7 Pro 一致。真机回执 `slot011-25042PN24C.log` 的 SHA-256 为 `ee1e05d4f596cae6e1ea876ce50a71be22a4e9093913d4c3050054d51926424b`，数子回执为 `d30fbdfdbba4118095f21a2f96db31df9a98d17c762c1cf465eaf7a80fac7f4a`。
