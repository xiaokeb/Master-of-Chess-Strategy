# 围棋主时限

本地双人新局使用全局时长设置。启用时黑白双方各有一份主时限，轮到的一方消耗自身余额，归零判负。对局持久化双方余额和当前回合起点。死子协商期间停止计时，续弈从规则引擎确定的行棋方恢复。现有无时限存档保持原设定。

中国规则允许由竞赛规程指定用时。本节点对应现有 App 主时限设置。赛事读秒方案须按对应玩法另定。超时胜负与数子结果分别记录，棋谱可重放超时事件。[中国围棋协会规则](https://wqwh.weiqi.org.cn/rules/)

80 项 JVM、NDK 双 ABI、Debug 与仪器 APK、Release Manifest 及原生规则专项通过。Lint 0 错误、25 条警告。Pixel_7_Pro 在 100% 和 150% 字号各通过正式设置开启、换手存盘、重新打开超时对局、唯一 Room 归档及回放。前两轮在测试设置定位阶段停止，最终用真实设置开关复验。已检查四张横屏截图，大字号终局余额可向下滚动查看。

以隔离 Room 记录模拟已经到期的回合。真实计时满额、熄屏／系统时钟调整和杀进程专项，以及人机与自动演局棋钟仍待验证或接入。
