# 围棋本地双人对弈音效

- 本地双人实战沿用围棋人机的落子和提子音效。确认正式终局后播放中性胜利提示或和棋提示。全局开关控制播放，页面退到后台或退出后停止接收新提示。
- 房间存盘成功后才发出提示。保存失败时保持静音，重试成功后只发一次。初次加载、存档恢复、悔棋、导入、展示方式切换和棋谱回放保持静音。
- 31 项 JVM、双 ABI 原生构建、Debug 与仪器 APK、Release Manifest 通过。Lint 0 错误、25 条警告。
- Pixel_7_Pro 用真实 Native 和 Room 在 100% 与 150% 字号各验证一次。首手存盘后播放，退出释放播放器，关闭全局音效再进原局时保留首手，第二手正常保存但保持静音。已检查四张横屏截图。150% 时下方对局操作仍需滚动，棋盘和顶部返回可见。
- 本次发布源码。实体设备试听与正式棋钟仍待验收。
