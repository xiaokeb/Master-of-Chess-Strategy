# 围棋终局审校图

`review-strength-groups.py` 新增 `render 槽位 输出.svg`。前两个位置参数仍为终局审校目录和原始评测目录。命令校验原始 MOCG、棋盘和棋块清单散列，读取对应终局，输出带零起点坐标的棋盘。标记落在工作表的棋块代表点上，A 表示无条件活棋，? 表示待判断，R 表示优先复核。读取后仍在工作表中记录裁定。

离线验证覆盖 140 局、2,412 个棋块，对照棋块标记数量、拒绝中断槽位和保护已存在的输出文件。仍有 1,858 组待审，当前草案没有符合导出条件的完整局。[评测续跑](2026-11-22-holdout-continuation.md)
