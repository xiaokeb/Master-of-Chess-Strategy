# 围棋自由摆局接入

编辑九、十三、十九路交点，可放黑子、白子或擦除，选择先行方。围棋的标准初始盘为空盘。开始时由原生规则检查棋盘尺寸、棋子、无气棋块和可下点。通过后才创建训练活动局，重开回到原始摆局，终局可回放和备份。训练棋谱不计标准胜场。

## 原生候选

摆局成为原生初态，落子、劫、提子及协议数子继续使用已发布规则。MOCG v6 在事件记录前保存原始棋盘和先行方，v1–v5 保持原行为。摆放的棋子不计入行棋数。KataGo 从同一原始布局建立历史，再重放行棋。

## 统筹接入范围

- 编辑页复用现有 JNI 的 SGF 恢复入口。SGF 根节点 `AB`、`AW`、`PL` 表示盘面和先行方。固定让子仍走原校验。棋谱载荷、回放与备份保留真实着数。
- 训练事务接收已校验初态和执色。恢复核对原始布局、先行方与活动记录的前缀。人机资格门禁沿用已解锁难度。
- 共享改动限于围棋棋谱载荷与自由摆局白方身份校验。复用既有构建目标、Room 模型和导航入口。

使用 NDK 30 为 x86_64 和 arm64-v8a 编译链接，原生 SGF 回归在 x86_64 模拟器通过。201 项 JVM 用例通过。Pixel 7 Pro 模拟器在 100% 和 150% 字号各走通一次九路白先、玩家执白、真实 AI 应答、重开原始盘面及终局回放。另一次备份专项验证原始摆局缺失或错配时拒绝准入，白方训练棋谱恢复后保留原始盘面和执色。六张画面已核看。

Debug 应用和仪器包、Release 主清单通过，Lint 为 0 错误、25 警告。十三和十九路的生产编辑交互、真实杀进程及实体设备留待后续专项。[发布清单](../../releases/manifests/v0.1.0-go-free-setup.1.json)
