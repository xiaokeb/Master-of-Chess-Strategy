# 围棋盲棋实施

正式需求的盲棋玩法采用棋子背面展示。新局设置提供选择，行棋时黑白棋子显示同一颜色背面，保留空点、最后落点和合法操作。无障碍描述也隐藏棋子颜色。进入数子或终局后恢复黑白颜色，便于核对死子与复盘。

模式随对局配置持久化。GAI1 v8 记录盲棋标记及可选时钟，普通无时钟、带时钟局继续各自编码。续局、重开、指定开局替换、自动接管、归档和备份均保留模式。Room 使用既有原始封装列，暂无 schema 变更。

成绩沿用既有来源规则。新建标准真人局使用原有创建证明；自动、让子与指定开局仍按原规则处理。初始证明与终局配置必须一致，不能在既有赛事中改写模式取得成绩。

## 验证安排

- 定向回归封装、原生记录准入、创建证明、模式切换、重开、指定开局与自动续局。补充 v8 时钟组合及版本标记损坏负例。
- 从正式入口开启九路盲棋，由真实模型应手，检查屏幕和无障碍描述隐藏颜色。返回续局后核对模式、身份和原生记录，认输后显示黑白原色。
- 验证备份原始封装及 Room 准入，检查普通与 150% 字号的正式页面。完成构建、Lint、模拟器与视觉检查后按节点发布。

已通过 141 项定向 JVM 测试，NDK 30 双 ABI、Debug APK、测试 APK 与 Release 主清单均生成。Lint 0 错误、25 警告。Pixel 7 Pro 通过两档字号的生产对局用例，以及独立 Room 备份恢复用例，共 3 项。六张画面确认行棋及续局显示统一背面，认输后恢复黑白。大字号终局控制区可滚动，截图保留认输操作后的滚动位置。实体设备待验收。
