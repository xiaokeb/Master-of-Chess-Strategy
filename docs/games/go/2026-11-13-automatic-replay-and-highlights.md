# 围棋自动演局终局棋谱与精彩收藏

从正式入口开始的单局自动演局，在双方确认死子并完成中国规则数子后立即固定终局并写入可回放棋谱。写入失败时保留原对局和盘面，页面可重试。重新进入会继续提交同一对局。保存成功前锁定悔棋、重开和更换指定开局。自动续局继续按原有顺序保存上一局，再回到指定开局或标准初态。

精彩收藏使用全局设置，支持大师档、至少 160 着（含虚着）和逆转。逆转采用项目口径：最终胜方在本局任一实际着法后，累计提子数曾落后至少五子。指定开局前缀、让子和死子协商均不计入提子差。算法从已经准入的 Native 棋谱逆向逐着读取实际提子量。收藏只在首次写入棋谱时设置，恢复、重试和手动取消收藏保持幂等。围棋正式胜负仍以双方确认的数子结果为准。

## 验证

- `goarchive1` 在 `3401045` 冻结 16 个源码及资源覆盖路径，包含倍速和音效。正式构建通过 57 项 JVM、NDK 30 双 ABI、Debug APK、仪器 APK 和 Release Manifest，Lint 0 错误、25 警告。实际提交的父节点另含国标麻将弃牌训练，两次变更路径独立，分别留存各自的构建和设备证据。
- Pixel 7 Pro 模拟器在 100% 和 150% 字号各通过 6 项。Room 和真实 Native 验证同一终局只生成一份棋谱、逆转判定和取消收藏后的重试。牌桌验证倍速恢复、双方计分确认与终局保存提示，并通过系统音频日志确认落子播放、关闭设置和退出释放。核看同源 APK 的 10 张横屏截图，字号已还原。设备收据位于 `.build/goarchive1/device-ae547842b0d4456aac54c5c34268d7cd/`。
- 实体设备听感、后台运行和棋钟另行验收。阶段发布仅含源码。
