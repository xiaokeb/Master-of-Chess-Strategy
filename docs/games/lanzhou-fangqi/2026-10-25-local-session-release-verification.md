# 兰州方棋：正式本地对局节点验收

节点 `v0.1.0-lanzhou-fangqi-local-session.1`；基线 `7a8c0956ac03311e0849d6641437b3e59e78c54e`，最终候选 `fqsp3`。本记录验收本地双人与完整历史存储链路，不代表完整棋种、题库或四档棋力完成。

## 已交付行为

从首页进入兰州特色棋，再进入方棋本地双人对局。原生规则负责合法动作、任意整数边长轴对齐成方、多方逐枚选择吃子、完整回合悔棋，以及整局历史首次重现禁重。正式开局为上两行14黑、下两行14红，中间三行空、红先；采用用户确认的项目规则，不宣称有统一官方方棋竞赛认证。

页面使用保留的VM持有Native会话。初始局面真正保存后才开放操作；动作保存确认后才继续，退出等待写入并释放会话，配置重建接回同一退出请求。重新进入恢复相同ID、模式、辅助次数与完整动作历史；损坏记录报错并保留，不静默覆盖新局。重开产生新ID，悔棋按完整回合扣一次额度。

方棋完整存档进入正式备份注册表；方棋gate → 围棋gate → Room事务采用固定顺序。恢复先校验完整Native历史，成功替换后旧写者失效；事务失败回滚数据，旧容器无方棋段时清除该活动槽位。数据库沿用既有schema 18，无破坏性迁移或应用数据清空。

原生动作在分配失败时回滚；JNI拒绝过大或无效输入。生产动作上限16384，单快照上限1MiB；写入前为本完整回合预留容量，达到限制时明确停止，保留棋局，不制造胜负。旧合法历史仍可恢复、备份及悔棋。独立低上限测试不能冒充真实走满16384次验证。

## 失败记录与未验收项

保留AI所有权、无进展停止与已存模式恢复能力，但新四档入口仍受正式PRD的学习/资格依赖约束；本节点没有新开放四档AI、授予棋力验收或发放成长奖励。教程、练习进度落库、提示、自动演局完整UI、四档强度评测、音效、题库规模、性能和实体设备均需后续节点验收。没有重复执行旧象棋评测或变更其他棋种桌规。
