# 兰州方棋功能与验收清单

依据 `docs/requirements/PRD.md`、`page-interactions.md`、原始需求第 2.4.5 节及 `coordination-decisions-2026-09-30.md`。本表区分源码、设备运行与最终产品验收。

| 功能 | 当前状态 | 验收缺口 |
| --- | --- | --- |
| 7×7开局、正交走子、非法动作原子拒绝 | 已发布原生/JNI规则和本地双人；本节点实际触屏走子/AI应答通过 | 实体设备 |
| 任意整数边长成方、旧方重组、多方逐枚吃子 | 原生/JNI规则与标准完整终局重放已验，实际最后吃子及视觉通过 | 更多组合的触屏覆盖 |
| 全局首次重复禁着、整回合悔棋 | 已有规则与交互测试；正式终局禁止悔棋，分级限制保留 | 四档完整辅助体验 |
| 吃光或封堵终局 | 标准红/黑终局Native验证，正式红胜实际落子/首次记账与故障重试通过 | 各种终局完整UI覆盖 |
| 版本恢复、历史重放与完整备份 | schema21/Native严格校验已发布；本节点实际备份Owner替换和正式局冷进程恢复通过 | 实体设备、更多系统退出情形 |
| 本地双人棋盘与交互 | 已发布正式菜单与生产存储，本节点4项设备回归通过 | 全横屏/实体设备 |
| 四档离线AI与解锁 | 正式入口、六课门槛、10/15/20可信胜场、实际简单/大师应答已验 | 中等/困难完整UI、耗时/功耗、棋力梯度 |
| 正式创建与首次结算 | 固定请求、活动槽冲突保护、绑定writer、重试/冷恢复不重复记账通过 | 成长投影、未完成局明确放弃流程 |
| AI 自动演局、调速、暂停 | 未实现 | 业务状态、后台限制、操作及设备测试 |
| 教程、残局和扩展训练 | 六课/三项基础练习及独立进度已发布，普通/150%字体和恢复已验 | 完整内容量与扩展训练 |
| 棋谱、胜场与成长记录 | 正式完整棋谱/首次收据/胜场和完整备份已发布 | 列表/详情、成长资料与奖励投影 |
| 难度顶栏、提示、认输及正式重开 | 正式重开/终局悔棋有保护；其余尚未完成 | 完整对局控件与视觉验收 |
| 音效与实体设备性能 | 未实现 | 来源/许可、实体设备验收 |

不得把“源码已写”或“双 ABI 链接”记为完整可玩。共享集成顺序由 `docs/development/integration-queue.md` 管理。

2026-10-31按[正式入口验收](2026-10-31-formal-entry-verification.md)更新。本表不计算跨棋种启动百分比，内容规模、AI棋力和最终产品验收独立跟踪。
