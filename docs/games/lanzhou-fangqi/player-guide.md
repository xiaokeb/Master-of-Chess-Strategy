# 兰州方棋操作说明

从首页进入“兰州特色棋”。“方棋规则与练习”提供六课规则和三项基础练习；课程需要逐课明确确认。练习必须由规则引擎判定通过且保存成功后才记进度。

“方棋人机对弈”显示各档解锁条件。完成六课后可选择简单；简单正式10胜后解锁中等，中等正式15胜后解锁困难，困难正式20胜后解锁大师。选定已解锁难度，再按“创建正式对局”。普通双人局、练习和旧无来源战绩不计入正式胜场。

有未完成对局时，按“继续当前对局”恢复原来的模式与难度。页面不会自动丢弃旧局，也不会把普通局转成正式局。创建失败时按“重试确认新局”，无需另选难度；它会确认同一请求。返回入口后可重新读取条件。

玩家执红先手，点击己方棋子，再点击沿横竖线相邻空点走子。新组成轴对齐正方形后，按提示逐枚选择敌子吃掉；吃子资格用完才换手。黑方由离线AI应答。悔棋按当前难度限制，终局不能悔棋。右侧内容可上下滚动。

保存失败时，按“重试保存”后再继续；不要把棋盘显示胜利当作已经记账。正式局的“重开”暂时禁用，已结算后返回人机入口明确创建下一局。退出应用后可从同一入口续局；完整备份恢复后使用新读取的对局。

当前阶段尚无提示、认输、自动演局/调速及正式音效；成长资料和棋谱浏览仍待接入。四档入口可用不等于棋力梯度已经验收。
