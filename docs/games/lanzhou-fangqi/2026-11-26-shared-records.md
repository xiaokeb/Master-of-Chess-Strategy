# 兰州方棋共享棋谱

从首页打开棋谱，在棋种筛选中选择「兰州方棋」。共享列表保留原收藏分类。打开记录后可逐动作前进、后退或跳到终局。回放复用正式棋盘，待吃和逐枚吃子各有对应位置。

正式棋谱的删除经确认后使用原首结事务记录删除标记并移除棋谱。首结与成长数据继续保留。旧数据恢复会换代，旧详情页退出后重新打开可读取新数据。

Pixel_7_Pro 三项用例通过。共享入口以真实首结记录验证按棋种筛选、收藏、回放、取消删除及确认删除。带斜杠和加号的记录 ID 能正确打开。删除后检查原首结一致。另验证了成方待吃与实际吃子的原生步骤，以及外层结果被改写时的拒绝。已复核终局截图，Android Lint 为 0 错误、25 警告。

Room schema 27 集成版在 Pixel_7_Pro 复跑三项，在 Xiaomi M2007J3SC 通过相同三项。MIUI 首次拒绝启动测试宿主 Activity。复跑时通过 ADB 将同一测试 Activity 启动到前台，界面测试通过，未调整设备权限。已复核真机 1080×2266 终局截图。回执与截图位于 `.build/fangqi-recorded-round1/`。
