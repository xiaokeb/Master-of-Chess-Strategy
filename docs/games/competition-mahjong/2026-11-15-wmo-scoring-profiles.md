# 国标麻将原生计分版本

按世界麻将组织《麻将竞赛规则》附件一核对三项计分。同样的牌组可用原生接口选择对应版本。[世界麻将组织规则镜像](https://mahjongclublausanne.ch/wp-content/uploads/2024/03/Greenbook2021_Chinese-EN.pdf)

| 番种 | 新版规则 |
| --- | --- |
| 绿一色 | 有发且与条子构成混一色时，可加计混一色。无字牌时可加计清一色 |
| 九莲宝灯 | 排除幺九刻。仍按和牌方式计可用的不求人 |
| 清幺九 | 分开的两组同序数刻子可以分别计双同刻。三同刻涵盖的牌组不再另计双同刻 |

原生命令日志 MOCM v1 使用旧计分。MOCM v2 使用新计分，原生牌局构造时选择规则，用同一规则结算、估值、悔棋和回放。错误版本在写入会话前拒绝。当前新规则由原生调用显式选择。正式赛事与自动演局还需贯通 JNI、外层档案、复盘和备份，设备端使用正式入口复验后再开放给新局。

NDK 30 两个 ABI 均构建 JNI 库及相关原生测试。Pixel 7 Pro 模拟器通过原逐番回归的 120 个场景和新增 6 个版本场景。实测同一九莲宝灯牌墙的两种结算，覆盖悔棋、回放和错误版本拒绝。原生自动会话测试通过，32 盘旧策略与校准策略的旧版日志散列与前次发布一致。
