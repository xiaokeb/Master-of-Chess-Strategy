# 国标麻将四档策略诊断协议

- 测量当前生产自动演局中的相邻等级 0／1、1／2、2／3。固定牌墙根种子 71425001–71425008，每个种子轮换四次，同种子使用同一套十六盘牌墙和决策种子。每次两席使用高档，其他两席使用低档，轮换后每个固定玩家各用高档两次、低档两次。三个档差合计 96 场、1536 盘。
- 每场按四席竞赛总分比较四对高低席。高档总分较高得 1，持平得 0.5，较低得 0。先求每个根种子下的换座平均，再对八个种子求均值，同时报告根种子得分范围、十六盘流局数及运行耗时。四次换座共享牌墙，以八个根种子为样本单位。
- 每盘最多接受 4096 个动作。遇到无法行动、非法动作或超限，驱动以非零状态停止并保留原始日志，报告失败，不补采或删去样本。运行时间用于诊断工具本身，不作为移动设备时延基准。
- 本轮种子供训练诊断，结果用于定位当前策略，正式 7:3 验收另以未见种子和事前锁定的容差执行。诊断不替代正式人机入口、四档等级准入或实体设备测试。
