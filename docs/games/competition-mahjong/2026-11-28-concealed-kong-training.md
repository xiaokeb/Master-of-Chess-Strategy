# 国标麻将暗杠后补牌自摸训练

第 29 题使用自编的完整 144 张牌墙。东家先暗杠手中的四张二万，原生引擎从牌墙尾补出东风。题面分步显示暗杠和补牌，再由玩家选择自摸。和牌后原生核对杠上开花 8 番、三家付款及普通自摸 1 番的排斥。

暗杠和补牌只更新题面。原生结算完成后才保存首通，增加 1 星、80 分。完成前 29 题累计 29 星、1,810 分。

## 验收

- 原生结算为 17 番，其中杠上开花 8 番。南、西、北各付 25 分，东家得 75 分。
- Debug APK 及测试 APK 构建通过。11 项 JVM 单测通过，Lint 0 错误、25 警告。
- Pixel_7_Pro 模拟器在 100% 字号通过暗杠与补花回归，在 150% 字号通过暗杠专项。核对了开题、补牌和结算截图。大字号下题面细节可纵向滚动，操作与结算仍可查看。
- 小米 25042PN24C（API 37，arm64-v8a，100% 字号）通过暗杠专项并保存 3 张截图。真机以临时 Debug 测试宿主运行，完成后恢复标准 Debug APK。
- 本节点覆盖第 29 题及补花回归。整场竞赛流程、其余设备与题库规模仍按各自验收计划跟踪。
