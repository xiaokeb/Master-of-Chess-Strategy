# 国标麻将回放优化后 500 场复测

Pixel 7 Pro 模拟器使用回放优化发布源码生成的 Debug APK。对照两次使用相同的四个种子、500 个独立赛事 ID 和相同的仪器测试源码。每次在独立 Room 数据库保存、导出、删除一条归档、恢复并重新打开数据库。

| 500 场混合策略档案 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 导出包字节数 | 19,189,522 | 19,189,522 |
| 导出 | 409.942 秒 | 341.393 秒 |
| 恢复 | 407.528 秒 | 341.644 秒 |
| 读档案列表 | 524 毫秒 | 531 毫秒 |

本次导出和恢复耗时分别缩短 16.7% 和 16.2%。复测在恢复后逐条核对档案身份、载荷字节、收藏与保存时间，活动档仍为校准策略，人类成绩表保持为空。
