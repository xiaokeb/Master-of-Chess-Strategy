# 国标麻将正式赛事宿主验收

从首页进入国标麻将后可选初始东、南、西、北位，再进入十六盘赛事大厅。四章教程全部保存后开放简单难度。大厅、牌桌、统计和历史共用同一 Room 座位仓库。页面使用固定存储代次，恢复失败并回滚数据库时也会拒绝旧页面访问。牌桌退出等待已接收写入与 Native 资源释放。

## 验证范围

- `cmfh3` 从 `9ea53524fa9ffc3e6326fa1cfb0c1a65734af7fd` 导出，冻结 1996 个文件。只切取共享导航与资源中的国标赛事改动。发布树加 3 份验收元数据，共 1999 个文件、38 个变更路径。Room 保持 schema 23。
- 6 组 110 项 JVM 均通过。Android NDK 30 LLVM 的 `arm64-v8a`、`x86_64`，Debug APK、测试 APK 和 Release Manifest 通过。Lint 0 错误、24 警告。
- Pixel 7 Pro 模拟器（API 37、x86_64、16 KiB）共采纳 38 个设备方法、40 次调用。正式候选执行 20 次，另从 `cmfh2` 继承同源的 13 项 Room 与 7 项生产备份测试，逐文件核对两候选之间的七处界面和测试变更。源档保留、显式确认、退出排空和恢复代次均有定向覆盖。
- 两档字号从实际导航进入，完成一次出牌并在退出后打开同一赛事。统计与历史验证了同库入口和空态。检查 22 张不同的原始截图。两档字号初次打开时均显示本家手牌，出牌操作和部分底部内容仍需滚动。未清除默认应用数据，字号和动画设置已恢复。

首轮候选的旧历史测试依赖未发布的分离存档适配器，后改用正式原子仓库测试。前一候选的提示正文正确，但两条 UI 测试使用了全文匹配，最终改为子串匹配并复验。视觉检查发现本家手牌位置过深，最终将本家手牌和操作移到对手信息之前，并将报和与提示并排。

设备已验证首盘出牌和同局续赛。仍需跑完十六盘，验收末盘撤回和重结算、非空历史收藏和删除、杀进程恢复、实体设备、完整横屏及音画。无难度与辅助历史的旧档保持原样，需补明确的保留旧档后新开赛事入口。更高难度仍待逐盘私有证据与可信胜场。发布仅含源码。详见[发布清单](../../releases/manifests/v0.1.0-competition-mahjong-formal-play.1.json)。
