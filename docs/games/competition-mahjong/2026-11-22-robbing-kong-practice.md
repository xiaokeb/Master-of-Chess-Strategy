# 国标麻将抢杠和实战

第 24 题把「抢第四张加杠」的规则知识转成可操作局面。题目用项目自编牌墙还原南家碰中、取得第四张中并宣布加杠的过程。本机坐西家，持十三幺听中。页面只显示本机暗牌和公开的加杠。

选择「过」时，原生规则完成南家的加杠并从牌墙补牌。练习保留原窗口供重选，过牌不发奖励。选择「抢杠和」时，原生规则核对西家和牌、南家原碰保持、牌墙不补牌、抢杠和 8 番，以及和绝张的排斥。页面显示四席分值。首通增加 1 星、80 分，全目录累计 24 星、1,410 分。[世界麻将组织《麻将竞赛规则》番种 47](https://www.mindmahjong.com/adobe/MCR2021.pdf)

实测总番 96，东 −8、南 −104、西 +120、北 −8。11 项 JVM 与 Pixel 7 Pro 共 4 项仪器调用通过，普通和大字号均走通两种操作，普通字号回归点和及错和。已核看 11 张画面。双 ABI、主包、仪器包和 Release 主清单通过，Lint 为 0 错误、25 警告。完整题库和实体设备待验收。[发布清单](../../releases/manifests/v0.1.0-competition-mahjong-rob-kong.1.json)
