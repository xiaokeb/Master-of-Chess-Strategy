# 国标麻将整场赛事与旧档保留验收

从正式赛事入口打开缺少难度和辅助记录的旧档时，先重放校验，再询问是否保留旧档并新开。取消时不建立正式座位。确认时核对同一来源，仅建立空的正式赛事记录。旧档字节随全量备份保留，开赛仍需完成四章教程。

## 验收

- 在 Pixel 7 Pro 模拟器用真实 Native 和生产 Room 仓库走完十六盘，第八盘后关闭并重开磁盘数据库。末盘撤回时同时撤回统计和成绩单，重结算后仅记录一场，前十五盘不变。备份恢复保留收藏和删除标记。
- 两档字号均从正式页面查看第十六盘、收藏、取消删除、确认删除，并核对统计仍保留。逐盘显示区分玩家编号与带单位的分数。全场由测试驱动真实动作，页面测试负责成绩单交互。
- 最终候选 `cmseries3` 通过 28 项 JVM、双架构 APK、测试 APK 和 Release Manifest，Lint 0 错误、24 警告。采纳 25 个设备方法、28 次调用。保留 `cmseries1` 的 25 次未受影响调用和 `cmseries2` 的整场复验，最终候选复验两档字号下的历史页面。测试原图 22 张，核看旧档和非空历史相关的 10 张。未清除应用数据，恢复了设备字号和动画设置。
- 冻结 1999 个输入，发布树 2002 个文件、8 个变更路径。Room schema 23。准备过程中误写的旧本地构建脚本已按归档中的原始补丁恢复，历史候选与收据保留。

本节点采用固定种子的整场样例。其他牌例、可信胜场与高难度、完整横屏与音画、杀进程恢复和实体设备仍待验收。详见[发布清单](../../releases/manifests/v0.1.0-competition-mahjong-formal-series.1.json)。
