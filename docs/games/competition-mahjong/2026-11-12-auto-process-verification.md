# 国标麻将自动演局进程恢复验收

在 Pixel 7 Pro 模拟器的专用 QA 进程中，使用隔离 Room 数据库和生产自动演局页面。夹具由 Native 逐盘生成，停在第十五盘结算前一事件。四席均采用简单难度。

- 点击「单步前进」后结算第十五盘。终止进程并重新打开，已完成盘数仍为 15，末盘尚未开始，活动检查点、Native 记录及累计比分一致。点击「下一盘」后进入第十六盘的第 0 个事件。
- 点击「继续演局」并等待末盘自动结算。Room 保存 16 盘及一份完整归档。第二次终止进程并重新打开后，终局、检查点、Native 记录及归档的散列一致，库内仍只有一份归档，人机成长结果为 0。
- ADB 在首次恢复取证后短暂断开。重连核对同一 PID、会话和检查点散列后，从第十五盘盘间状态继续同一次运行。字号恢复为原值 `1.0`。

候选 `cmautoproc1` 通过 78 项 JVM、NDK 30 双 ABI、Debug APK、仪器 APK 与 Release Manifest 检查。Lint 0 错误、25 警告。设备上通过 1 项夹具测试和两次专用进程终止及恢复，核看盘间、末盘开始、终局与恢复画面共 5 张。视觉复核确认状态文本与牌桌相符，恢复后侧栏回到顶部，下方控件可滚动到达。[发布清单](../../releases/manifests/v0.1.0-competition-mahjong-auto-process.1.json)

本次发布源码。模拟器证据覆盖专用 QA 进程里的生产页面与 Room，生产入口的进程恢复、熄屏后台执行及实体设备另行验收。
