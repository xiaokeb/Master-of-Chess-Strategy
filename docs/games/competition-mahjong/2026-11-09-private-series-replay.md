# 国标麻将逐盘私有证据

旧版正式 Room 保留正在进行或刚结算的一盘 Native 日志，过去各盘只保留公开结算。逐盘证据用于重新算出整个赛事的结果，旧公开成绩没有足够数据重建牌局。

## 重放门槛

- 使用原赛事的种子、初始观察玩家和盘号取得该盘的种子、庄位、圈风及观察座位。
- 先对比新建 Native 会话的 MCMS/MOCM 版本及初始牌墙，再用 Native 重放。普通存档恢复使用档案中的牌墙，仍保留该兼容行为。
- 只接受真实终局。十六盘必须齐全、按序，逐盘的分数、和牌者、点炮者与番数都要与原账本一致。MCMS v1 每盘最多 16,559 字节，十六盘原始日志最多 264,944 字节。

## 正式换盘与备份

- 新开正式赛事从首盘跟踪。MCTX v2 在原有事务内容后增加有序日志段，记录数等于当前盘号（从 0 起算）。当前盘仍由 MCMT 保存。换盘校验上一盘的种子和结算后，将它与新当前盘原子写入；一次失败的写入保留原当前盘及原证据。MCTX v1 字节格式照旧，已存在的赛事继续以 v1 保存。
- 第十六盘结算时校验当前日志。末盘撤回移除公开结算，前十五盘日志保留，重结算再次校验末盘。收藏和删除成绩单继续保留当前赛事的日志。
- 备份使用原有国标正式备份条目，恢复 v2 时在写库前校验已结算的日志及账本。每席最多增加 248,446 字节的 MCTX 数据，四席十六进制备份最多净增 1,987,568 字节，计入现有扩展区总上限。旧版备份可由新版读取，带 v2 证据的备份需要支持 v2 的读取器。后续调整原生洗牌或规则时，须保留旧版的证据重放入口。

## 接线边界

### 正式 AI 策略复核

- 正式入口的新赛事使用 `POSITION_SEEDED_V1`，MCMT v5 保留此策略以及原有辅助、播放与提示回执。已有 MCMT v1–v4 继续使用原批次策略，重新开场才启用新策略。
- 新策略按每个公开局面生成下一步 AI 种子，批次只用于播放与一次写盘。悔棋或恢复使批次在不同动作处分割时，剩余动作仍可逐步验证。
- 新策略证据从配置重新生成牌墙，重放玩家动作、重新推导各 AI 动作，并逐字节核对原始日志。已结算盘还须匹配公开账本。备份候选的未结算当前盘也通过策略复核；缺少 MCTX 证据段的新策略赛事会被拒绝。
- 旧策略日志仍可验证牌墙和结算。新策略证明动作与指定难度的当前算法一致，真实强度需单独评测。若未来更改洗牌、公开牌面种子算法或 AI 选择算法，必须能按旧版策略重放已存证据。

隔离候选 `cmstrategy1` 基于 `d69a690`，叠加 16 个明确路径。双架构 Debug APK 与设备测试 APK 构建通过，9 组共 161 项 JVM 测试通过，Lint 为 0 错误、24 警告。初始回执选择器误列了冻结源中不存在的未跟踪提示测试，核实后按实际九组 XML 生成回执。MCMT v5 的 JVM 用例覆盖四种元数据组合，包括提示回执。

Pixel 7 Pro 模拟器共 14 项通过。相同牌墙上原批次策略产生的合法终局能通过规则重放，按新策略或错误难度复核时会拒绝不匹配的动作；正式新策略通过十六盘、末盘撤回与备份往返测试。正式入口成功出牌、自动推进并重开同一场。已检查入口、统计、历史、牌桌、出牌按钮及续赛六张横屏截图。测试回执和截图散列在 `.build/cmstrategy1/`，未清除模拟器应用数据。

### 跨场保留与成长

MCTX v3 在同一 Room 行中保留已完成的新策略赛事证据。每条包含赛事 ID、种子、AI 等级和十六盘的玩家动作。每个动作占两个字节，保留类型、牌和顺子起点。AI 动作和牌墙由种子、座位和策略重建。首次归档要求重建的十六份 MCMS 原日志逐字节相同；备份恢复还要检查难度映射、逐盘公开成绩和统计。已有 v1、v2 字节格式照旧。已有 v2 新策略赛事若完整且仍是当前赛事，可在后续保存时归档。

跨场记录按座位和赛事 ID 去重，保留结算顺序。末盘结算与公开结果原子落库，撤回时同事务移除，重结算生成一条。公开成绩单删除及启动下一场仍保留档案。单席档案上限 8 MiB，超限会拒绝本次结算写入并保留已存数据。四席正式条目的理论上限合计低于 90 MiB，仍计入共享备份的 128 MiB 扩展区上限。大档案的恢复时延和容量边界待专项评测。

隔离候选 `cmarchive1` 基于 `d69a690`，叠加 17 个明确路径。162 项 JVM、双架构 Debug 构建和 14 项 Pixel 7 Pro 模拟器测试通过，Lint 为 0 错误、24 警告。模拟器覆盖末盘归档写入失败后重试、撤回再结算、删除成绩单后新开赛事、跨场档案恢复，以及拒绝缺少玩家动作的档案。已检查正式入口、统计、历史、牌桌、出牌和续赛六张横屏截图，未清除应用数据。详细散列见[发布清单](../../releases/manifests/v0.1.0-competition-mahjong-series-evidence.1.json)。

下一步根据已复核的名次投影胜场、星级和积分，再接难度解锁。恢复含较高难度的备份时，先从同一候选备份验证成长证据，再按候选权限准入活动赛事。旧结果继续用于原有统计。
