# 国标麻将赛事音效

正式十六盘赛事复用全局音效开关和项目已有的短音频。弃牌、吃碰杠、和牌、错和和荒庄使用不同类别的提示。其他席一批动作只播放一条提示，盘结束优先。识别只读取公开牌桌和本机提交结果。

赛事保存成功后发布声音。写入失败保留待播放提示，成功重试后消费一次。打开存档时不重播历史。退到后台或离开牌桌停止播放，离页释放播放器资源。

设备专项从正式导航打开隔离 Room 赛事，验证实际弃牌播放和退出释放，再从设置关闭音效。返回同一赛事后检查历史操作保持安静，另开赛事在庄家首轮再次弃牌，检查静音是否生效。实体设备听感与独立自动演局的音效另行验收。

本节点沿用项目已发布的 WAV 样本，没有引入新依赖或外部音频资源。[音源验收](../../testing/2026-09-14-chinese-chess-sounds.md)
