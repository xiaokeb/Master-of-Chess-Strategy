# 国标麻将正式赛事策略版本

新建正式赛事使用通过独立样本的校准策略。每次机器人动作仍由当前公开局面派生种子，策略随赛事保存。下一盘、续局及逐盘重放读取已保存版本。官方和牌、错和、四席计分与学习门槛沿用现有规则实现。

| 数据 | 策略标识 |
| --- | --- |
| MCMT v1–v4 | 历史批次调用 |
| MCMT v5 | 原版局面种子策略 |
| MCMT v6 | 校准局面种子策略 |
| MCTX v3 跨场档案 | 每场使用原版局面种子策略 |
| MCTX v4 跨场档案 | 每场携带策略字节，1 代表原版，2 代表校准版 |

归档恢复用对应版本与原始种子重建十六盘日志。备份准入拒绝未知策略及与日志不匹配的策略，正式写入仍走已有 Room 事务。原版和校准版可以共存于同一档案库。自动演局的生产存档另有 MCAU／MCMA 版本边界，待独立接入。

42 项 JVM 测试、双 ABI Debug APK、仪器 APK、Release Manifest 和 Lint 通过。Pixel 7 Pro 的 7 项设备用例验证了既有回放、新策略逐盘日志、十六盘结算与撤回、损坏备份拒绝、完整导出恢复，以及 100% 与 150% 字号的正式新建和续局。核看两档字号的牌桌和续局截图，共四张。实体设备的用时与长局资源占用待验收。
