# 国标麻将策略升级与旧档兼容

当前四档配置已进入正式赛事与自动演局。原生诊断显示简单与中等差距较大、困难与大师差距较小。[诊断结果](2026-11-14-strength-diagnostic-results.md)

1. 保留现有合法动作选择器的逐步行为。先新增仅供诊断调用的候选策略，使用同一套训练牌墙比对候选。确认收益前不迁移生产策略。
2. 正式赛事的旧批次策略和 `POSITION_SEEDED_V1` 保持原实现、种子和行动顺序。候选通过后为新赛事引入独立策略编码，活动、归档与备份携带该编码。旧赛事恢复、可信成长及归档逐步重放仍使用原策略。未知编码在写库前拒绝。
3. 自动演局的活动与私有归档包含合法事件历史。新活动采用新策略时，外层活动与原生 MCMA 配置均固定其版本。旧活动、固定开局、归档导入及续赛事根据原活动版本打开。
4. 新策略先核验同一公开视角及相同种子复现、改变其他家的暗牌和墙顺序后决策一致、和牌与吃碰杠合法、两套历史合法恢复。再验生产备份、真实进程重开和回放。训练可复用诊断种子，正式 7:3 验收另冻结样本与容差。

首个诊断候选复用前次 96 场牌墙、换座和高低席比较。简单档随机弃牌比例固定为 20%，其余弃牌优先最小向听。遇合法认领机会以 60% 概率沿用中等档的杠、碰、吃顺序。大师档在余牌不超过 32 张时，对公开剩余较多的弃牌增加扣分，并按对手公开副露数调整扣分。中等、困难和正式入口配置使用现有策略。

首个候选同样本比较得分为 84.77%、75%、50%。基线重跑的 96 场分值、动作数与流局数逐项相同。第二个候选仍使用这一训练样本，将简单档随机弃牌设为 8%、合法认领设为 80%，大师档改为听牌时提高可达八番的进张与额外番值的权重，移除首个候选的弃牌风险扣分。
