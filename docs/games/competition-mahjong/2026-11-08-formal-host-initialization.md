# 国标麻将正式宿主首次初始化

正式备份已在 `38aadf62f195f11b0a7497f54a8bfc87a6a84fb3` 发布。首次打开赛事需处理有旧档、已有正式档和空座位三种情况。

- 有旧档时先做只读预览，沿用现有MCMT、历史、统计和Native准入。预览和取消均不创建正式归属。明确确认后重读旧源，完成Native校验，再在写入事务内核对同一来源标识及目标状态。正式归属和MCTX同时写入，保留旧档。
- 空座位初始化为明确空MCTX。写入失败不留下空载荷归属，允许重试。已存在的正式载荷走恢复入口，首次迁移不能覆盖。
- 正式宿主接线时从同一Room读取独立MCLP资格，捕获固定代次并在旧写者排空后领取持久归属。赛事、统计、历史共用一个仓库，备份恢复后每个入口都检查原代次。持久归属和页面代次需要分别验证，因为回滚会保留数据库归属。

从 `9ea53524fa9ffc3e6326fa1cfb0c1a65734af7fd` 导出的 `cmfi1` 只覆盖3个源码和测试路径，共1971个构建输入。27项JVM、双ABI APK、测试APK及Release Manifest通过，Lint 0错误、24警告。Pixel 7 Pro模拟器通过11项Room与7项生产备份回归，实测预览无写入、确认中途来源变化、SQLite首次写入故障后重试、已有正式载荷保护。设备未清应用数据。

本切片纳入正式宿主节点一并发布。首页、赛事、统计、历史的生产路由及正式席位选择仍需集成。
