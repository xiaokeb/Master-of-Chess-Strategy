# 国标麻将 500 场备份复测

在 Pixel 7 Pro x86_64 模拟器上使用逐行备份读取节点的冻结 APK，按既有四个种子和 500 个赛事 ID 生成自动演局档案。经生产备份导出、删除一条、恢复及重开 Room 后，逐条核对载荷字节、收藏和保存时间，活动档仍一致，人类成绩没有新增。

| 指标 | 本次实测 |
| --- | ---: |
| 导出包 | 19189522 字节 |
| 导出 | 332269 毫秒 |
| 恢复 | 321373 毫秒 |
| 进程采样最大 PSS | 227662 KiB |
| 进程采样最大 RSS | 332908 KiB |

约每 15 秒采样一次，共 43 次。数值覆盖档案生成、导出和恢复期间的整个应用进程，含 Java 与原生内存。短于采样间隔的峰值可能未被捕捉。期间主机也执行了围棋构建，耗时仅记录本次观测。实体设备和接近 128 MiB 的真实档案仍待验收。
