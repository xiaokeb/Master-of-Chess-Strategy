# 国标麻将牌墙末张自摸训练

第 28 题追加在已有目录末尾。玩家坐北家，原生引擎从自编的完整 144 张牌墙重放到最后一次摸牌。题面显示北家手牌、公开花牌与最后摸到的东风。原生视图继续隐藏其他三家的暗牌。

打出东风后，其他三家均过，牌墙耗尽，本盘流局。选择自摸时，东风作将，原生计入妙手回春 8 番，三家分别支付底分和本盘总番。两张花牌分开显示，不计入起和门槛。第 28 题首通增加 1 星、80 分，累计 28 星、1,730 分。

规则及原生案例见[牌墙末张验收](2026-11-24-last-wall-scoring.md)。

## 验收

Pixel 7 Pro 实测起和 31 番、花牌 2 分、总番 33。北家得 123 分，东、南、西各付 41 分。打出东风后的流局不授奖，自摸首通仅写入训练进度。

11 项 JVM 测试通过。模拟器在 100% 和 150% 字号各通过一次新题测试，普通字号另通过旧题「牌墙末张点和」回归。核对了手牌、流局反馈和结算共 9 张截图。NDK 30 双 ABI、Debug 主包、仪器 APK 构建通过，Lint 0 错误、25 警告。

2026-11-28 在 Xiaomi 25042PN24C（Android API 37，arm64-v8a）验证末张自摸与末张点和，保存六张真机截图。初次仪器测试未成功带起窗口，复验使用临时 Debug 宿主从 ADB 启动。末张自摸以设备端 JUnit 完成记录和结算截图核对，末张点和另有完整仪器回执。测试使用独立数据库，结束后装回原候选 APK。回执位于 `.build/cm-last-draw1/device-25042PN24C/`。
