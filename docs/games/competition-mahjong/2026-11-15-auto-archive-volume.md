# 国标麻将自动演局档案容量

通过生产自动演局存储与备份入口验收混合策略档案。选择四个原生种子，各完整行进十六盘，生成一份旧策略和三份校准策略样本。以独立赛事 ID 扩展为 100 或 500 场，档案与活动档均保留原策略版本。复用种子只用于形成存储负载。

每组在独立 Room 库保存资料、读取列表、收藏一场并导出。关闭并重开数据库后删除一份归档，再从导出包恢复。恢复后重新打开数据库，逐条核对标识、保存时间、收藏和载荷字节，并核对最后一场校准策略活动与归档仍存在、人类成绩表为空。
