# 需求文档

项目文档.md 是保留原样的完整需求来源，包含 BRD、PRD、页面交互、任务分级、接口示例和提示词模板。

正式开发优先读取以下精简文档：

- BRD.md：产品定位、目标、范围和业务约束。
- PRD.md：产品结构、核心系统和产品级验收。
- page-interactions.md：页面布局、状态和交互规则。
- chinese-chess-rules.md：中国象棋坐标、基础行棋、胜负与分片边界。
- ../development/task-levels.md：阶段依赖、完成状态和进入条件。

拆分文档引用原始章节并只保留实施所需规则，避免重复读取长文档。接口示例和提示词中的名称仅供参考，正式命名以代码及已批准设计为准。
