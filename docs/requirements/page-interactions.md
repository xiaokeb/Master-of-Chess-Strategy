# 页面规划与交互规则

来源：项目文档.md 第 2.2 节。正式实现采用单 Activity + Compose Navigation；原文的多 Fragment 表述视为参考结构，不作为技术约束。

## 全局规则

- 横屏优先，内容必须适配不同尺寸和系统窗口区域。
- 一级页面提供一致的返回入口；支持系统返回，手势返回按 Android 平台能力实现。
- 操作即时反馈，非法操作说明原因。
- 对局和关键进度自动保存，退出或异常关闭后不得静默丢失。
- 运行状态、数据加载和错误状态均由不可变 UI 状态表达。

## 首页

- 左侧占约 40%：人物形象、段位、总胜场、星级和积分。
- 右侧占约 60%：五张棋种入口卡；兰州特色棋在二级选择中区分方棋与老虎吃羊棋。
- 点击棋种进入模式面板，再进入难度选择；锁定难度显示条件。
- 长按棋种快速进入上次模式与难度；首次使用或无历史时不触发快速进入。

Foundation 壳只验证 40/60 分栏、主题和原生状态，不冒充正式首页。

## 对局页

- 顶部：棋种、难度、时长、返回和设置。
- 中部：自适应棋盘或牌桌，支持清晰选择态、合法落点和动作反馈。
- 底部：悔棋、提示、认输、重开、手动/自动、调速。
- AI 思考、暂停、终局、恢复失败等状态必须禁用冲突操作。
- 自动模式支持 0.5x–4x、暂停和可配置续局；默认玩家先手。

## 残局页

- 顶部章节导航，中部关卡网格，底部进度摘要。
- 前一关通过后解锁下一关，当前难度完成后解锁下一难度。
- 支持棋种相关主题筛选；首次奖励与重复挑战状态分离。

## 中国象棋扩展玩法

- 扩展目录只允许进入已经完成的玩法；未完成项明确标注后续开放，不创建空壳对局。
- 自由摆局默认载入标准局面，可清空或复原，支持红黑棋子、橡皮、先行方和已解锁 AI 难度。
- 将/帅、士/仕、象/相必须满足基础区域约束，双方各有且仅有一个将帅；超出标准棋子数量时拒绝开始。
- 开始前由正式规则引擎恢复局面，并要求对局未终结且存在合法着；失败只给稳定原因，不创建存档。
- 自由摆局保存当前局面及不可变原始局面，重开回到原始摆局；完成后生成棋谱，但不计入排位胜场和难度解锁。
- 限时挑战提供每步 10、30、60 秒三档；每次换手给新行棋方完整时限，思考、AI 搜索和应用后台时间均计入。
- 限时归零立即判当前方负并播放对应终局音效；活动对局可恢复，终局生成棋谱但不计入标准排位胜场。
- 连胜模式由玩家执红；同一难度累计 3 胜升级、累计 2 负降级，简单与大师分别作为上下界。
- 胜利累计当前与历史最佳连胜，失败或和棋中断当前连胜；终局只能进入系统计算的下一难度，活动系列可恢复。
- 连胜模式生成专项棋谱但不写入标准排位胜场，避免通过扩展玩法绕过普通难度解锁条件。

## 教程页

- 每个棋种独立维护规则讲解、分步练习和知识测试。
- 完成教程解锁简单难度；跳过策略必须由后续产品决策明确。
- 可从知识点跳转到对应练习残局并保留返回位置。

## 其他一级页面

- 棋谱：分类、收藏、步进回放、速度控制和显式导出。
- 个人中心：总览、分棋种统计、成就和人物外观。
- 设置：默认难度、自动续局、音效、时长及本地备份/恢复。
