# 业务需求文档（BRD）

来源：项目文档.md 第一章。本文是正式开发摘要，原始文档保持不变。

## 产品定位

《棋术大师》是一款纯单机、无广告、无内购的横屏综合棋类 Android 应用，服务日常对弈、残局训练、棋力提升和 AI 自动演局。产品覆盖中国象棋、围棋、国标麻将、兰州麻将、兰州方棋和老虎吃羊棋。

## 用户价值

- 棋类爱好者：获得不同难度的人机对战和系统训练。
- 兰州及西北用户：使用本地特色麻将与民间棋规则。
- 进阶用户：通过高强度 AI、经典残局和棋谱复盘提升棋力。
- 休闲用户：通过自动演局和趣味模式离线消遣。

## 业务目标

| 目标 | 验收方向 |
| --- | --- |
| 规则完整 | 官方规则、本地规则及边界局面均有可追踪测试 |
| 难度梯度 | 简单、中等、困难、大师四级可配置且体验逐级增强 |
| 内容规模 | 最终残局总量达到 9000+，按棋种、难度和主题索引 |
| 玩法覆盖 | 人机、自动演局、残局、教程、棋谱及扩展训练模式可用 |
| 运行体验 | 主流 Android 设备操作流畅，大师级 AI 单步目标不超过 2 秒 |
| 离线可信 | 无 INTERNET 权限、账号、云同步、广告或内购 |

以上性能、体积和内容数量是交付目标，不在工程底座阶段视为已达成。

## 业务范围

范围内包括六类棋种、普通对局、AI 自动演局、残局闯关、新手教程、棋谱管理、段位成长、成就和本地设置。扩展玩法包括限时、连胜、盲棋、自由摆局、棋力评测和每日残局。

范围外包括真人联网对战、账号体系、云同步、广告、内购及任何运行时联网能力。

## 核心约束

- Android 使用 Kotlin、Jetpack Compose、NDK C++ 和本地持久化；Python 只用于离线数据生产。
- C++ 统一使用项目锁定的 Android NDK LLVM，不调用 MinGW。
- AI 优先评估成熟开源引擎；引入前必须完成许可证、版本、体积、ABI 和移动端性能审查。
- 最终安装包目标为 200–300 MB，优先保证棋力和内容完整度。
- 业务数据仅保存在本机；导入、导出和备份必须由用户主动触发。
