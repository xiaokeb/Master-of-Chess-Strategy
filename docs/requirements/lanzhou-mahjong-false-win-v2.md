# 兰州麻将炸胡计罚补充规格 v2

依据：用户明确选择“按项目最高单家胡牌付款，每家24倍”。本规格仅覆盖兰州麻将炸胡计罚，优先于旧8倍占位；不是兰州官方统一规则或可靠地方文献的替代声明，不影响其他棋种。

## 计罚

- 炸胡者向其余三家各支付 `底分×24`，总支出 `底分×72`，全桌增量零和。
- 不再额外叠加自摸、点炮倍率或依据炸胡者当前牌型重新加番；此前已发生的杠分独立保留。
- 24是本项目最高合法单家胡牌付款 `3×2³`，不是把自摸三家合计收入当作单家罚额。七对与本人杠上开花互斥，不无条件叠加全部加番项。
- 例如底分2，三家各收48，炸胡者支出144；无其他杠分时四席增量为 `[-144,48,48,48]`（按实际炸胡座位重排）。计罚前检查乘法与累计分值整数溢出，不得产生部分付款。

## 旧局兼容

新建局采用原生LZMJ规则v2（字节4为2）；历史v1仍按每家8倍恢复、重放、悔棋与重存，不能静默改判或清除旧数据。未知版本拒绝且不改变原状态。

LZSR外层v1/v2是容器身份，均可持有任一合法LZMJ规则版本，完整原字节保留；既有108张Room容器variant不是计罚版本。恢复必须先固定原生规则身份，再完整合法重放，不能只校验校验和。

## 验收边界

需分别验证新旧计罚、四座位/不同底分、杠分保留、溢出原子拒绝、终局恢复与悔棋、容器及正式Room/备份往返。本决定不宣称App接线、设备页面或整个棋种已经完成；实际证据与剩余任务按专属状态逐节点维护。
