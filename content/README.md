# 内容目录

本目录用于残局、棋谱和教程内容的生产流程。raw/ 保存本机原始素材，generated/ 保存可再生成的中间产物，两者均不提交。

只有通过合法性、来源和许可证检查的发布资源才能进入 Android 模块。

manifests/ 保存每个已发布内容批次的来源、作者、许可和验证清单，必须提交。

`manifests/release-content-v1.tsv` 是当前发布内容的机器清单。Android
`preBuild` 校验残局资产和定式源码的路径、SHA-256、项目自编许可声明及
对应来源说明；新残局文件不在清单时构建失败。哈希校验只证明审核后的资源
没有漂移，不代替人工来源或版权审查。外部内容必须先补齐独立许可方案与
审查证据，不能伪装为项目原创。
